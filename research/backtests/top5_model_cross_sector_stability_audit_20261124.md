# 固定TOP5模型排序：跨行业适用性与稳定性审计（2026-11-24）

## 一、事实结论

- **当前不能证明模型排序稳定。** 正式主分支 skill/TREND_BUY_CANONICAL.md 与唯一19:00任务要求：Python先冻结同三级行业至多5只，模型检索公告/财务/产业受益、预期与反证给 model_rank/model_reason；之后Python机会分决定正式 attention_rank，模型名次仅同分及评分缺口时回退。由此历史正式TOP5收益好坏不等于模型的排序收益。
- 当前模型研究提示覆盖了共性检查：扣非/现金流、订单、新产品、主营、预期变化、技术相对强弱与风险；**没有显式的按行业盈利机制选择主导变量、目标1日和3日分别排序、对同一冻结输入重复独立排序或跨行业一致性验收**。行业跨度上具备通用事实核验要求，但未验证普适预测排序能力。产业趋势榜中的按商业模式核验领先指标不能自动等于已在个股模型中逐行业使用。
- 历史39个已冻结TOP5组中有12组能够看到5只的历史模型名次：银行6、线下药店2、白色家电2、高端PCB1、电子化学品1。部分5只名次为[1,2,4,9,11]等，说明历史记录不是固定5只内部统一的连续1–5名次；不可视为完全按新实验规约独立研究固定五只的标准样本。且不少是连续交易日重复股票。
- 最近相邻记录中的同主题共同股票两两优先关系一致32/37（86.5%），来自7次相邻观察比较，药店10/10、白电6/6占较大比重，银行名次有反转。**这只衡量不同日已存档名次关系，不是对同一输入多次独立运行的稳定性**；也不等于预测正确率。
- 原已存档路径直接完整拥有D1/D3收益的完整模型名次仅5组；补入后续双源已核对收盘后，在统一短持有期回放有7组。7组观察中，模型名次优先TOP1在相同样本上D1+0.598%、D3+0.272%，原正式TOP1在相同样本上D1+0.331%、D3+0.202%。只调整两组榜首，差值+0.266/+0.070个百分点，3日逐日留一观察日敏感性可由正转负。极小、日期相关、银行与药店占优，不能推断各行业通用。
- 11-23模型记录的次日回测：电子化学品模型TOP1光华科技-4.56%、当日正式原TOP1万润股份+0.09%；高端PCB模型TOP1沪电股份+1.73%、原榜首崇达技术-3.88%；银行模型TOP1交通银行+0.56%、原榜首邮储银行+0.51%。三组都不能证明行业普适性、也没有当日开盘买入可成交收益与3日成熟结果。
- **稳定需要两个不同测试**：(1)同一输入独立重复运行时名次是否稳定、每一对调序是否来自一致证据；(2)未来跨行业、跨日期冻结后D1/D3实际收益与原序相对表现是否稳定。当前只存在第一项的弱替代观察，第二项是小样本、回顾性。

## 二、研究用跨行业模型提示词草案 v0（仅研究，不用于正式任务）

身份：仅对Python提供的当日冻结固定TOP5进行产业/公司/定价研究与排序；不得增删候选、不得改变READY/WAIT或执行买入；不得查看未来收益或历史榜单原排序、回测结果。

**共同输入**
- 指定截止时点（北京19:00，或单独次日06:30追加的隔夜消息），冻结行业的核心催化、SW三级行业、五家公司代码、截至时点公告与定期报告、同口径行情/成交/历史资金估算、估值、相对市场/行业强度、当时可得监管/海外参考、来源时间及缺失标志。
- 06:30不得拿后续国内交易日价格或重新选股，19:00不得读取其后美股收盘或次日盘中。仅对照同一主题的五家公司，以相同信息覆盖标准研究；不以UNKNOWN等同否定。

**第一步：判定当前真正驱动股价的机制，而不是贴行业标签**
- 指明当期具体变化是需求量、产品价格/价差、成本、订单交付、新产品渗透、资产质量/利差、政策、渠道库存、用户付费、商品价格还是估值风险偏好；至少提出一个可核验反证。
- **按产业商业模式选择有效变量**，严禁对所有行业强套利润同比、PE、主力资金：银行/保险关注净息差、信用成本、资产负债和资本；医药零售关注客流、同店、门店效益、医保与费用；游戏/内容关注新游流水、留存、商业化、版号、研发投放；硬科技制造/电子化学品关注客户认证、量产、真实产品收入、良率、产能与价格成本；资源/黄金关注基准品价格、自有产量、成本、套保与利润敏感度；航空航运关注票价/运价、载运率、燃油/运力；家电消费关注品类、渠道、销量、出口、成本与汇率。行业不在上述举例时，从商业模式推导其专属盈利驱动，不得套近似品类。
- 只用与本轮催化直接相关的变量给出公司相对受益链条：事件 -> 产品/客户/订单/价格量 -> 收入/成本/利润 -> 边际变化 -> 市场已定价程度；每个箭头标 FACT / INFERENCE / UNKNOWN 以及来源截止时间。

**第二步：同组差异比较**
- 对每只公司逐项分析：①对本轮驱动的真实受益力度与受益兑现时点（不能用行业标签代替主营收入占比）；②是否有新增、独立于同行的事实及反证；③10/20/60日市场认可、最近5日资金参与持续性（注明真净额或价量代理）、趋势阶段/收盘结构；④是否已被预期透支（此前涨幅、可核实预期、短线拥挤和阻力），不能因涨得多机械降级；⑤未来1日与3日的独立驱动及不利情景。
- 业务信息未核实时标UNKNOWN并降低排序置信，不得凭主观给虚构估值目标、订单规模或超预期。
- 至少挑出最可能领涨的两家公司和最有力的相反证据，比较二者的“领先证据”，不是按固定跨行业权重打分。

**第三步：分别预测D+1、D+3**
- 对固定5只输出两个完整无重复名次 rank_D1、rank_D3（各1–5），允许不同；D+1侧重新增催化、资金承接、短线定价，D+3侧重已验证驱动持续性和日内波动/交易拥挤风险，均不得用未来开盘价。
- 对每只输出：驱动事实（来源时间及原文链接）、核心反证、对照另一只的优劣、短期领先条件、领先失效条件和置信度 HIGH/MEDIUM/LOW/INSUFFICIENT；高置信度必须由多条相互独立证据支持。
- 对完全不能区分的候选仍给出完整关注序，但明确 LOW/INSUFFICIENT 与“证据不足，不建议因模型研究调整原序”；不能为了展示“模型能力”强行调位。
- 只把模型研究顺序及证据交给后续Python验证；绝不把排序当作买入指令，执行和资金风险由独立Gate负责。

## 三、如何检验“提示词跨行业稳定”

1. **冻结输入与单一提示词版本**：从银行、游戏、药店、家电、PCB、电子化学品、资源、运输、制造等不同机制各抽取多个不重叠信号日，同行业公司信息覆盖率对等。用统一格式只给截至时点的证据，不给未来收益或历史原序。若已见历史收益只能作有偏开发集。
2. **同一输入重复至少3次**：保存每次模型和提示词版本、五只名次、每个相对排序依据，计算Kendall成对一致率、TOP1重合率、与客观事实是否一致、虚构/引用错误率。稳定≠完全不变；名次改变应有证据或承认临界不确定性。
3. **独立新日期冻结后回放**：统一比较Python原序、模型D1/D3、模型修正Python三条研究序列；分行业/信号日统计D1/D3同组超额、TOP1/TOP3、配对序、收益为正频率、最大收盘回撤；单日多主题/多日同股票按日期及事件聚类，避免重复把同一机会当独立样本。不可只挑模型改序且成功的股票。
4. **可成交性**：信号日晚间不能成交，另测下一交易日开盘入场及盘中经Gate触发入场的情形，排除一字板、加入滑点与费用；A股新仓T+1，D+1开盘至当日收盘仅浮盈，不是当天买卖实现收益。
5. **准入条件**：至少在多个不同商业模式中，独立测试同时显示可解释的D1/D3增量收益、合理的名次重复稳定性、重要反证和缺失来源处理，且排除一个最大贡献事件后仍有正向或不显著为负的贡献；小样本、结果分叉时保留原序，不宣称“适用所有行业”。不凭固定阈值直接上线。
