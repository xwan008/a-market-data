# 趋势买点前置权重｜统一公式历史影子回放（2026-10-17）

> **研究性反事实回放，不是正式榜、交易指令，也不改变70/30生产规则。** 机器可复核的完整名单与统计见 [同日 JSON 审计](./trend_buy_weight_shadow_20261017.json)。

## 口径

- 使用当前 `scripts/build_trend_buy_manual_research.py` 的基本面分与机会分；技术特征仅取信号日及之前的65–180根日K，未来收盘价只在排序冻结后计算收益。
- 对每个三级行业，先由70/30确定当时可用的动态Top5（第五与第六分差不超过0.03时允许第六），然后对所有策略固定相同研究名额，以防研究席位数量变化混淆结果。
- 基准70%机会+30%基本面；对照60/40、50/50，以及“70/30选前K-2 + 其余2个席位按基本面分独立选择”的双通道版。所有版本都服从当日技术准入，不给 `COOLING` 或 `FAILED` 分配新建仓研究席位。
- 只衡量**前置候选**的收盘后未来等权收益与尾部下跌情况；不重做公司独立深研，也不模拟READY、止损、滑点和真实买入成交。

## 关键解释

1. **没有跨样本统一最优的比例。** 风电调权不改变名单；固态电池50/50在5日窗口改善约0.53个百分点；银行70/30次日和两日都略好。
2. 固态电池经历了板块级显著下跌：70/30的21只里19只在5日内累计跌幅超过3%，50/50仍为19只。降低机会权重没有解决整体下行风险。
3. 10月9日固态电池的002074、603906在当前规则的当日历史重建中处于 `COOLING`，因此40只而非42只进入权重比较；此处是**用现在规则回放过去**，并非冒充当时正式榜。
4. 风电9只仅覆盖当时冻结的风电零部件三级行业，不包括今天扩展的全部风电设备范围，结论不可推广到全板块。
5. 市场历史序列用截至10月16日保留的日K向过去截断；代表股票002487（9月29日）、002709（10月9日）、601288（10月14日）与原提交的共有K线逐日核对未见收盘价差异，但**尚未完成所有股票历史文件的逐一同SHA校验**。

## 决策与下一步

- **本轮不修改正式70/30**。样本仅3个板块日期、且银行右删失，不能依据样本内收益最优值调参；前置候选收盘收益不等于真实买点触发后的策略收益。
- 后续保留全量 `lightweight_scanned`、各分项得分、技术排除原因、源提交SHA与名单，积累跨日期、跨市场阶段的独立样本；比较1/3/5日收益、胜率、≤−3%风险、行业内超额，并单独追踪最终Top5和READY。
- 权重选择采用先期样本确定、后期样本验证的时间顺序；持续对照70/30、60/40、50/50和双通道，不把某只涨停造成的均值改善视为稳定优势。
