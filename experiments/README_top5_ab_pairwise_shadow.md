## B的四维可比证据

1. 近期趋势：5日收益差超过2个百分点、5日上涨天数相差至少1日、10日最大收盘回撤差超过3个百分点。至少2个指标形成实质优势且优势指标多于反向指标，才判该维领先。
2. 当前结构：5日突破，以及此前1～3日已成立的收盘承接/刺破收复。承接辅助证据需要当日量比至少1.3、收盘位置至少65%。增加承接只算这个维度的证据，不直接获得整体第一。
3. 量价：当日量比差超过0.30、5日量比差超过0.20、收盘位置差超过8个百分点、20日相对强弱差超过3个百分点、5日上涨/下跌成交量之比差超过0.30。至少两个优势、且多于反向指标，本维才判胜。
4. 参与位置：与MA20的距离相差超过1个百分点，较接近一方在该维领先。MA20仅作位置代理，不是承接失效或交易止损。

跨维比较：至少2维胜且0维负，或者至少3维胜且最多1维负，才确定强优势。其余为未分出优劣的并列证据梯队。同梯队显示顺序沿用A，仅为了阅读，绝不暗示B给出了精确内部名次。

所有阈值是实验开始前登记的暂定材料差异标准，不是回测优化。对阈值统一乘以0.75与1.25做敏感度检查，比较成对优势变化；缺乏数据不补中性分，也不虚构止损或R。
