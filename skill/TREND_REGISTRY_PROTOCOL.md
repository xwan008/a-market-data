# A股板块趋势榜｜唯一正式研究与发布协议

> **唯一业务规则入口**：「A股板块趋势榜」每次执行（06:30和18:30）都必须先完整读取并遵循本文件。本文件规定通用研究方法、状态判断、有效趋势复核、退出判断及发布纪律，不包含上一轮热门主题或推荐名单。**06:30读取上一有效收盘的观察/候选/确认趋势做增量复核；18:30必须先独立完成并冻结全市场发现，再读取上一轮完整趋势账本。**
>
> **每天的正式研究只有三步**：模型独立发现 → 观察/候选/确认连续复核 → 合并判断、校验发布。Python只负责客观行情计算和必要技术校验，不作为第二个趋势发现者。产业T等级、市场状态和个股READY风控相互独立；新仓优先通常0–3个、没有合格确认行业时允许0个及空handoff，绝不为凑榜降低标准；尚未确认的观察/候选仅在D1—D3验证期跟踪，D1/D2/D3任一阶段确认后按当前市场结构持续复核；D3未确认强制终结本轮并退出。新异动/衰退/失效不进入有效跟踪池。

## 0. 研究标准、产业阶段与市场状态

**产业链、商品价格第一锚与A股个股买点分开判断，但商品领涨与股票趋势仍在同一趋势榜和同一状态流中推进，不另建独立商品榜。** 研究对象是未来可能持续的产业景气及其在A股的市场体现；发现候选不等于趋势已确认，确认产业趋势也不等于立即值得买入。

1. **产业链的领先变量与未来1–2季度驱动**：判断未来1–2个季度盈利改善是否存在可核验路径；分开核实政策落地、产品价格/价差、库存与供需、订单与交付、产能利用、成本/毛利传导和经营利润。区分已发生事实、前瞻条件、未证实假设。单一政策口号、热点新闻、市场涨幅不足以证明盈利已改善。
2. **产业T阶段（证据成熟度而非股价级别）**：T0拐点观察——产业领先变量发生有来源的变化，但需求/利润传导尚不完整；T1准景气确认——多类有效证据支持未来1–2季度产业或盈利改善的驱动，关键传导与潜在反证已审查，尚未充分兑现；T2正式景气——有真实订单、供需、价格/价差、盈利或利润率等互相支持的兑现证据，产业链条相对充分。资料不足则待核验，不强凑T1/T2；正式迁移仍服从现行程序Gate。 **T等级仅表示产业证据成熟度，不是市场趋势强度、趋势确认可信度或交易价值评级；不得仅凭T0/T1/T2标签提高市场状态、趋势排名、买点研究优先级或下游准入资格。** 真实的订单、供需、价格、盈利等产业事实仍须独立核验，可用于评估驱动持续性及风险，但不能用T标签代替原始证据。
3. **趋势市场阶段**：A股直接形成的趋势按相对强度、上涨广度、成交、价格结构、龙头与中票扩散及分歧承接判断；**主要商品直接形成的可核验价格趋势，可用商品自身多日价格结构、报价、供需与独立佐证推进同样的观察→候选→确认市场状态**，不要求先等A股价格反应。新异动为早期异动；观察为有跟踪价值但尚未确认；候选趋势为量价与扩散出现初步共振但持续性待验；趋势确认为市场结构、广度、相对强度与分歧承接获得相互支持的可靠确认；根据截至本轮有效收盘已掌握的真实证据判断，不设固定上涨天数、累计窗口或单日广度比例作为确认硬门槛；高潮/衰退为过热或扩散明显衰减；失效为按真实结构反证确认市场趋势结束。**状态不是必须逐级经过的机械序列**，要依客观证据判断；D1—D3是本轮机会验证期限，不是板块历史首次上涨日期、价格连续上涨天数或产业生命周期。
4. **正向证据、反向证据和失效条件**：每个进入正式有效趋势池的主题都要有具体正向证据，主动核查至少一项潜在推翻路径，写明指标、条件及原判断何时应被修正；对关键产业结论尽可能用不同原始来源和不同证据类型交叉验证。若当前未找到真实反证，应注明“尚无已核实反证”并明确可证伪条件，**不能编造负面事实凑数**。同源转载不等于多源交叉。
5. **统一按真实驱动确定第一锚**：分别核验可观察的订单、交付、产能、产品价格、供需、库存、成本价差、盈利等**与该行业真实商业传导相匹配**的领先变量，明确可得时间和证据质量，再独立检查A股核心行业结构。所有行业均需解释主营和利润受益，不能以股价同涨替代实质传导；不得预设某个行业天然比其他行业更易确认。
6. **市场背景、投资工具与交易资格分离**：在产业和市场分析之外，核实整体成交、流动性和风险偏好对A股扩散及新仓时机的影响；宏观弱势不能自动把产业T等级下调。任何交易工具的价格、成交或资金变化不能反向替代独立产业驱动证据。

**产业与市场的独立判断**：产业T阶段评估景气证据成熟度，市场状态评估趋势结构，二者不能相互替代。尚未确认的观察与候选在D1—D3期限内持续复核、D3未确认则退出；已确认后因真实新反证临时降级者按独立市场迁移及退出规则复核，不产生个股行动研究资格；只有趋势确认且至少存在一个独立确认、真实受益的CORE/DIRECT申万三级行业时，才可进入本轮新仓研究交接。产业T等级本身不额外构成准入门槛。新仓优先通常0–3个，合格不足可以为空，不得为凑榜降低标准。个股买点及风险边界由独立流程判断。

**统一状态判断**：上一轮产业T等级和市场状态只是待复核结论，不能构成本轮额外迁移门槛。每轮依据截至有效收盘真实可得的正反证据，重新评估有效跟踪方向与独立新发现；充分证据及时升降级，不要求逐级变化或固定上涨天数。此前已核实且未被证伪的产业事实可沿用，不得伪称当天已重验；证据不足时HOLD，具体列明已有信号、缺口与下轮验证重点。市场迁移须有可溯源的新增结构证据及独立佐证，产业利好不能代替市场趋势确认；独立价格锚须以该锚自身结构与相应供需证据判断，不能由A股反应一票否决。短期量价窗口、广度及量能统计仅供辅助，任何单一阈值或固定等待期都不得自动决定状态。

### 0.1 趋势确认时点与核心结构连续性

确认和降级以当时可获得、可追溯的独立证据为依据，不等待集体爆发才确认，也不因普通分歧自动降级。历史复盘与短窗口统计不能代替当轮证据；不同产业驱动及市场级异常流动性日应分层比较，不得依据混合样本统计设置自动确认或自动降级门槛。审计字段及下游资格以第3节为准。

1. **优先评估结构形成，不等待集体普涨。** 候选主题在每轮收盘复核时，按可用的3/5日价格结构、相对强度、核心与中位股分布、量价、关键支撑与分歧承接，以及互相独立的产业证据，判断“原有趋势是否已可确认”，而不把本轮涨幅排名、单日普涨广度、放量大阳当成确认必需条件。若在市场普跌时有核心群体持续强于市场且回调未破坏价格结构，应主动复核是否已经形成趋势，允许按足够证据在当天直接确认；**一两只领先股、一次抗跌或单个涨停不等于行业确认**，缺少群体和跨维证据则维持候选并写明真正的证据缺口。既不要求连续上涨固定天数，也不把连续回调固定天数设为禁令。
2. **记录确认的“首次足够证据日”。** 从当次允许读取的候选/确认历史记录及截至各日实际可得的客观快照，逐日核对是否有早于本日的可靠市场结构证据。若确认恰逢板块大涨或高潮，`change_reason`必须说明此前候选为何还不足、今天补充了什么独立关键证据，并评估过热与失效位距离；如果发现过去判断迟缓，明确记为“确认滞后审计”，不假装过往已正式确认，也不以未来涨幅倒推过去证据。
3. **真实核心链优先，外围扩散单独记账。** 复合主题先说明原确认的主要产业链及已核实真实主营的核心样本、跟随样本和仅外围关联样本，核验当前研究对象与此前的一致性。某个外围子行业或样本量不足的关联行业出现单日普跌，不能在真实核心产业链的3/5日结构、相对强度及关键承接仍健康时，**单凭“多细分同步扩散消失”**把整条主题从确认降回候选；必须指出哪一条原确认所依赖的核心证据确实损坏。核心链自身实质破位、跨独立维度同步恶化时，不得借“原来仍强”推迟当日降级。
4. **确认/降级迁移与交易参与分离。** 初次降级前比较新增结构反证与上一确认依据的强弱，明确是普通分歧、核心结构破坏还是整个市场趋势证伪；证据不够时应HOLD并注明分歧风险，不为了稳定榜单而僵化保持。确认日如已大幅拉升、远离可核验失效位或收益风险比不足，报告必须说明“趋势确认不代表适合买入”；候选与观察不得进入股票handoff；已确认行业仍需独立核验买点与风险。禁止以“为了提前买入”为理由降低证据可靠性。
5. **确认与降级审计**：新确认、维持或降级的判断须在`change_reason`、`state_history.reason`及迁移审计中记录核心研究对象、结构形成时点、分歧承接和最强反证；禁止借未来行情追改历史确认结论。单个回测案例不能替代通用证据标准。

### 0.2 同一趋势池与独立定价依据

1. **统一趋势池**：`research/trend_registry.json#trends`是唯一正式趋势研究列表，连续跟踪`观察`、`候选趋势`和`趋势确认`，不另设商品或观察池；状态不必机械逐级迁移。观察和候选不产生新仓研究资格。`research/trend_handoff.json`仅交接第3.3节规定的已确认方向与独立确认的A股三级行业。
2. **使用真实驱动对应的可核验定价依据**：若核心领先变量是一个独立可报价的基础市场价格，先核实标的、合约/现货性质、报价时点、多日结构、供需与反证；按照现有数据契约使用`trend_basis=COMMODITY`和`commodity_anchor`（`instrument`、`trade_date`、`price_basis`、`source`、`trend_reason`）。第一锚已形成可靠趋势时，可独立推进同一榜内的观察/候选/确认；下游A股反应有时差不自动否决第一锚，产业T阶段仍按实际需求和利润传导独立确认。此机制基于**客观驱动类型**，不限定某个品种名称。
3. **现有申万三级行业独立受益校核**：沿用当期申万三级行业数据，不重新创建映射系统。直接核验每个三级行业的主营受益与市场表现，最受益的一组行业可先确认，不等待其余宽主题行业普涨。正常A股主导趋势仍须结构、广度、相对强度等证据。若商品是第一趋势锚，三级行业可以在其`industry_assessments`里如实标注观察/候选而商品趋势先确认。
4. **先行驱动确认与个股行动资格始终分离**：即使基础市场第一锚本身已确认，若A股三级行业尚未独立确认，则`in_new_position_priority=false`且不产生股票handoff；已确认的行业仍需核实CORE/DIRECT实际收益传导，股票是否READY由独立的价格结构、入场触发、风险边界判断。**任何上游价格上涨都不能直接冒充下游公司的利润改善**。
5. **跨时区报价时点与反证**：北京时间18:30是本榜研究截止时点，不是海外交易所的统一收盘时点。商品第一锚应以**研究截止前可核验的最新一个已完成交易时段结算价/正式收盘价**为主要历史价格基准，辅以截止前可核验的当时盘中报价；两者分别注明合约、报价类型、所属海外交易日、可获得的真实时区时间、原始来源。可依已完成交易时段的多日结构和独立供需/事件证据确认趋势，不要求获得尚未结束海外交易日的当日结算价，也不得把“今日未结算”本身写成D3不确认的决定性市场反证。不能用盘中报价冒充正式收盘、把过期数据当成最新已完成报价，或使用北京时间18:30之后才公布的信息倒推本轮。真正缺乏已完成交易时段的可靠多日价格证据、持续性被实质反证，或供需主驱动缺乏独立可核实佐证时，才分别说明市场确认的实际缺口；订单/资本开支/利润兑现不足单列为产业T与A股受益传导风险，不能独立否决商品自身已经可靠形成的价格趋势。

### 0.3 单日爆发的发现与确认边界

**单日爆发只能提供发现线索，不能单独构成趋势确认依据。** 若本轮是仅凭单日大涨、放量、集中上涨或全市场同步普涨而新发现的方向，最多以`market_state=观察`进入现有正式趋势榜并持续复核；不得因为涨幅/广度/量比非常突出就直接设为候选或确认。若无可核验的真实研究对象或基本来源，则按已有新异动/未核验审计解释，不编造成观察。**该规则针对“只有单日爆发证据的新周期”**。曾经出现过的旧方向，若上一episode的D3未确认结论此前已经冻结，即使到本轮才正式清理退出，只要本轮独立扫描已冻结真实新异动，就应在同一收盘先记录旧退出、再以本轮触发日建立新D1；不以清理日期充当真实结束日期，不回溯历史首次上涨日；已确认且仍在榜的旧趋势再次加速不重启D1。初次发现时如已有充分、当时可得的多日市场结构和独立产业证据，则D1可直接确认，不受仅凭单日爆发规则约束。

做状态判断的**必答证据顺序**（允许客观并行采集，但研究结论必须逐项解释）：

1. **市场外围环境与资金性质**：检验大盘、风险偏好、流动性、市场级异常集中资金流入、政策性/事件性普涨及风格切换；市场层面资金冲击造成的同步上涨只作背景，不能冒充独立产业确认。异常交易日与常态日分层审计；出现异常集中资金交易时，不得在缺少持有人级可靠证据的情况下推定具体买入主体。
2. **行情引爆点（主催化）**：指出最早可得的一手催化事实（公司正式披露、监管文件、订单/产量/交付、政策或商品报价）、事件发生/发布/研究可见时间，拆分**已证实事实、市场预期、尚待兑现假设**。事件的规模、持续窗口、可逆风险和是否早被计价必须分析。无可归因主催化，不得仅凭板块大涨包装为产业趋势；没有新闻并不自动否定已有供需/订单/价格等持续性基础驱动。
3. **真实产业链与受益传导**：沿用已有申万三级行业，区分核心实质供应/主营受益、次级跟随与题材蹭概念。核实上游投入、关键组件、制造交付、渠道销售及下游需求等真实产业环节的技术、订单、交付、定价和利润传导；不得把某个产业主体的计划或预期直接当作其他关联公司已经获得实际订单。若仅为主题概念相关，须注明受益证据缺口。
4. **市场持续结构**：核心三级行业的真实多日走势、相对市场优势、成交、成分股广度、回撤承接和反证是否构成**此前已存在并在本轮仍成立的连续证据**。首次单日涨停/成交放大仍是观察；后续有真实持续证据时可升候选；多日结构、核心受益和独立市场/产业事实已足够时及时确认，**不机械设必须等待N日或外围全部普涨**。从已有观察或候选升级当天恰好大涨，必须证明并注明“确认所依赖的以前和当天的独立证据”，不能把当日大涨本身写成唯一确认理由。
5. **确认时点与买点独立**：记录本轮是否只有单日爆发、主催化的事实与兑现阶段、独立核心行业支持/反证、首次足够证据日及没有确认的具体缺证；若首次确认时已明显加速，记录迟到/过热风险。确认不自动READY。仅凭单日爆发的历史统计不得替代本轮连续结构和独立证据。

**判断顺序**：爆发提供发现线索；可核实的持续驱动与真实受益解释持续性；市场结构和独立佐证决定候选或确认。缺失的证据必须写入正式账本；独立价格锚的多日结构与供需驱动无需先发生单日爆发。**商品趋势确认不以油服等下游新增订单/资本开支/利润完全兑现为前置条件**：这些是后续产业景气、具体三级行业真实受益和新仓资格的独立问题。对商品价格趋势的关键反证应优先检查该商品的多日结构、报价可靠性及独立供需/事件持续性，而不是把A股某一弱细分或海外当日未结算变成一票否决。

## 1. 执行模式与三步主流程

### 1.1 06:30｜上一有效收盘版增量复核

读取上一有效交易日正式趋势账本中处于观察、候选趋势或趋势确认，且产业生命周期未失效的方向，对真实隔夜增量证据进行复核；无新事实则保留原状态与证据日期，不在早间改写正式收盘registry/handoff。已确认真正退出的方向不再自动继承；正式榜内观察方向必须继续读取、复核，不得遗忘。**读取上一收盘Registry/Handoff时执行下述历史输入只读校验，通过后再复核。**校验失败时报告REGISTRY_BASELINE_UNAVAILABLE。

### 1.2 18:30｜正式收盘研究

确认交易日期、收盘行情完成度和行业覆盖；仅在全市场扫描确实完整时将`scan_audit.full_market_scan_completed`记录为true。质量不足时阻断且**不能把本轮未发现解释成旧趋势失效**。

1. **独立发现**：研究模型先覆盖全行业及主要概念板块客观数据，再结合当期量价、行业/产业证据独立发现；**不能因旧池或热门板块限制扫描范围**。在独立首轮冻结前只可阅读本协议及当期客观证据；在没有读取上一轮registry/handoff/历史名单或旧候选转述前，冻结当日独立发现的方向、当前证据和反证。未知事实不得编造。独立发现可以为空，不能因为旧方向的名字而补齐。
2. **辅助交叉验证与连续复核**：独立发现冻结后，读取当日且时间口径有效的 `data/research/theme_evidence_snapshot.json#crosscheck_shortlist`（程序先按申万二级分类和已核验产业主题聚合、去重，再以当日相对强度30%、上涨广度20%、跨三级细分共振25%、成交参与强度15%、近期价格结构10%综合评分，只输出**0—3个方向的单一综合榜**；权重是可回测的辅助研究优先级，不是趋势状态Gate）。模型首次独立发现冻结后，必须逐一查漏综合榜，对未发现方向补充调查并在正式审计中记录补漏或排除理由；短期3/5日为负不可单独否决客观单日爆发的D1观察资格；程序排名不得自动决定D1，也不得把程序补漏伪称首次独立发现。不排除模型已发现的方向，也不为补漏预留名额：重合则核对证据，未覆盖则补充研究，冲突则解释分歧；同源行情不能冒充独立证据。程序名单仅供复核，不能自动决定T阶段、市场状态、正式入榜或新仓资格。名单缺失/无效须标记辅助数据缺口，不得伪造复核结论，也不阻断模型独立研究。随后从GitHub读取上一轮Registry/Handoff，先运行下述「历史输入只读校验」，PASS后只复核其中处于**趋势确认/候选趋势/观察**且生命周期未失效的方向。对这三类方向保留历史证据和连续状态；真实证据不足时HOLD，充分时迁移。降至观察仍是下一轮必读对象。新异动、高潮/衰退、失效无需逐项复核；在新一轮独立发现中同名出现，必须建立本轮新episode_id及新first_seen_trade_date，不读取旧历史。旧episode在先前交易日已冻结D3未确认、仅因历史存量清理而于本日退出时，若本日模型独立发现已冻结真实新异动，应同日先退出旧episode、再新增D1观察；此处不是用新证据替旧周期续命。
3. **合并、退出校验、发布**：将本轮观察、候选趋势、趋势确认写入**同一正式账本**；新异动、高潮/衰退、失效按真实证据退出；D1观察必须保留到D2复核，D3未通过按期限到期Gate退出，不继续保留观察/候选。旧有效趋势退出时，在`scan_audit.state_migration_gate.exits`记录真实原因；结构性退出必须有当轮独立市场反证，D3期限退出必须有完整终局审计，两类退出不能混用证据；不生成额外历史文件。状态迁移Gate和registry/handoff成对Gate都通过后，才能安全提交两份正式文件并READBACK。

**辅助覆盖补充（不改变发现独立性和市场资格）**：先完成并冻结模型全市场独立发现，再读取`discovery_coverage_audit`等辅助计算结果。主动检查申万二级指数（若有真实可得报价）和三级行业的结构分歧、相对抗跌但广度不足、多日量价线索以及商品/运价等独立价格和供需证据。三级行业聚合只构成二级分类代理，**不能冒充二级指数行情**；外部价格锚缺乏可核验来源或截止时点时，必须标示未覆盖，不许填造价格。复核提示不受原程序3个名额截断，但不代表每个提示都已深度研究，更不得自动写入正式趋势、改变状态或产生下游资格。重要线索未完成研究时须区分资料缺口、研究否决与容量延期。首次直接进入候选时，需分别说明可信产业驱动、核心受益传导及多日结构；累计涨幅配合宽泛宏观利好不足以自动入候选。候选不强制等待财务利润完全兑现或固定天数，市场状态和产业T阶段继续独立判断。

### 1.3 当期发现方向的落选审计

18:30独立发现冻结后、正式发布前，必须对**本轮模型已发现但未进入观察/候选/确认正式趋势池**的方向，以及**当日程序交叉复核名单 `crosscheck_shortlist` 中未进入正式趋势池**的方向，逐一解释去向。对程序名单同时记录是否已被模型独立覆盖，以及一致、补漏或冲突的复核结论；同源行情不得当作独立置信度加成。仅在已核实属于同一产业研究对象时合并审计，并列明对应原信号。程序完整计算快照中未进入最多3个复核名额的信号只保留排序/容量事实，不冒充已研究或否决。原模型独立发现冻结顺序不变；客观扫描分数只是复核线索，不能自动决定趋势资格或回填独立发现。

对每个落选方向至少说明：①当期可溯源的正向量价及产业证据；②市场结构（广度、相对强弱、3/5日等参考窗口、量能、核心与中票扩散）和产业盈利/供需/订单传导分别有哪些真实反证或未核实环节；③**没有进入正式池的决定性原因**，明确区分「当日反弹/新异动尚未确认」「产业证据不足」「市场结构未确认」「过热/衰退」「资料不足未完成复核」等，不能以“涨幅不够”“未入选”“排名靠后”代替分析，也不能编造反证；④哪项具体可验证的新增证据将触发下轮独立重新发现或重新评估。短期窗口为负、单日放量或固定上涨天数都不得成为机械一票否决项。

在正式Registry的`scan_audit.candidate_disposition_audit`中保存本轮**落选解释快照**（建议字段：`candidate_name`、`covered_industries`、`origin`、`decision`、`supporting_evidence`、`market_assessment`、`industry_assessment`、`decisive_reason`、`missing_evidence`、`recheck_trigger`），并在中文报告中按重要性摘要展示；来源或当日数据无法取得时明确标记`UNVERIFIED`，不得伪称已完成排除研究。最多3个复核名额之外的客观信号，保留在已有计算快照及其原始排序中，必要时汇总容量缺口；不得误写为模型已研究后否决。未形成有效信号的普通行业不需逐项列举。

落选审计只说明当轮决策，不创建额外观察池；已纳入正式榜的观察、候选、确认方向仍须连续复核。新发布版本必须满足第3节的确认审计、下游资格和第2.2节的单日爆发复核规则；研究证据或落选原因不足时，应如实披露缺口，不得冒充已完成核验。

## 2. 状态迁移与D2/D3审查

### 2.1 持续跟踪、状态迁移与退出

**三种情况要分开处理：**

- **普通波动**：单日调整、局部分歧、某只龙头走弱或资金流出，不自动升降级；若核心证据仍成立，HOLD并记录风险。不能把“旧状态未被新事实推翻”冒充“今天已重新确认所有事实”。
- **A股真实退潮**：当日或已有行情显示市场结构发生实质恶化，且上涨广度、相对强弱或核心与中位股承接等独立反证提供支持时，按统一状态迁移规则及时下调market_state，**不要求固定天数，也不另走紧急通道**。若同日主要股票普跌、关键支撑真实破位，应及时审查而非机械等次日；即使相对抗跌也需独立核实自身结构。
- **产业关键驱动证伪与新证据**：产业T等级和lifecycle_status的下降，必须有商品/政策/订单/供需/盈利等**产业自身**新反证，不能只因A股板块下跌而标产业失效。当前跟踪周期的阶段提升不能只凭单日反弹；已退出方向重新被独立发现时，必须用本轮新证据独立认证，不能继承此前的失效或确认结论。

退出新仓榜不等于产业失效；A股market_state=失效不自动等于lifecycle_status=已失效；映射不足不等于产业不存在。原有历史状态必须忠实保存，实际新状态变化须写真实原因和日期。

**独立定价依据与跨市场**：以独立市场报价为第一锚的方向须核验报价、产品价差、库存/供需、A股实际利润受益传导及本地市场结构，不以同步上涨代替实质受益。涉及上下游传导时，应区分产品售价、投入成本与实际价差；跨市场报价须注明时区、现货/合约性质及是否最终收盘。数据及研究资源充足时，可附5/10个相关市场交易日的条件性情景、反证和到期回验；**前瞻/回验是辅助研究，不是当日正式发布的新增硬Gate**，也不能直接决定当日状态。资金流向同样仅可作注明窗口、口径及日期的辅助证据，不能单独改变状态或排名。



**正式趋势账本`research/trend_registry.json`保留已确认且仍有效的趋势（包含经真实新反证降级、仍需评估是否退出者），以及D1—D3验证期内尚未确认的观察/候选；D3未确认不得继续留榜。** 三种市场状态共享正式账本，研究到期退出不等于产业逻辑失效。

1. 本轮独立发现且具备观察/候选/确认真实证据的方向进入正式账本并承担下轮复核义务；新异动、高潮/衰退或失效按核实结论在报告中说明，不自动持久化。
2. 上轮仍有效的每个方向，本轮必须明确继续跟踪或有证据退出；独立扫描未命中，不等于该方向已经失效。
3. 继续跟踪时保持原`episode_id`、首次发现日期及`state_history`连续；观察↔候选↔确认等任意合法状态迁移均须本轮新增结构证据，不设机械等待天数。
4. 退出时直接从本轮`trends`移除，在`scan_audit.state_migration_gate.exits`记录旧episode、具体退出理由和审计证据。**结构失效**使用`exit_reason_code=MARKET_INVALIDATED`，仍须本轮市场结构反证及独立广度/相对强弱佐证；**D3截止未确认**使用`exit_reason_code=D3_NOT_CONFIRMED`，以冻结的D3最终审计和具体证据缺项合法退出，不需要虚构市场已破位或产业驱动已失效。校验器禁止无审计退出和漏审删除。
5. 行情覆盖不足、交易日不一致、独立扫描失败时正式发布必须BLOCK；不得据此推断旧趋势失效。
6. 同名主题后来再被独立发现时，按本轮新证据建立新周期，不继承旧判断、首次发现日期或旧证据。

**D3期限退出**：第三个实际有效收盘仍不满足趋势确认条件，必须`NOT_CONFIRMED`并按专用`D3_NOT_CONFIRMED` Gate退出，禁止例外保留观察/候选、D4、POST_D3。期限退出是本轮机会研究结束，不能代替结构失效或产业生命周期失效；如数据不全或审计缺失应BLOCKED，不编造市场破位。对`trend_basis=COMMODITY`的D3判否，必须独立判断**截至北京时间18:30已经完成的海外交易时段**是否存在可靠的多日价格结构与供需/事件佐证，并具体列出价格结构不足、真实反证或来源不可验证的证据；**“海外当日最终结算尚未产生”“油服/工程资本开支或利润尚未兑现”均不得单独作为商品市场D3判否的关键依据**。真实市场证据仍不足可如实D3未确认退出，不因跨时区修复而自动确认。

**退出不建立额外历史文件。** D3最终冻结结论放在`state_migration_gate.exits[].d123_final_audit`，Git提交保留历史。独立发现阶段不读取已退出记录；发现冻结后可核查同名旧周期的退出时点与本轮新增异动，但不能继承旧结论。

**迁移/退出**：沿用原`scan_audit.state_migration_gate`和`state_history`，D3期限退出有独立Gate，不复用市场退潮的COUNTER硬条件。对一个曾经**独立确认**的三级行业降级时，迁移审核的当轮COUNTER事实必须注明`industry_code`并直接指向该核心行业、具备结构性强度及真实日期。外围其他行业的跌幅不能替代它。商品方向升级和降级必须同时具备商品自身重大`MARKET_STRUCTURE`与`COMMODITY_ANCHOR`维度证据；**商品正式退出**还需独立供需或产业基础反证，不以A股广度替代。

### 2.2 本轮机会的D1/D2/D3验证

**D1/D2/D3是当前episode的限时研究复核阶段，而不是产业历史首次爆发日、连续上涨日数或整个趋势生命周期。** 同一板块上一周期结束后，只要出现可溯源的新增异动（新催化、关键价格结构变化、相对强度或参与结构实质改善），就可由本轮正式发现日重新D1，绝不追溯历史首次爆发。已有活跃episode禁止重启D1；旧产业故事未变、普通整理或研究者重新命名，不构成新D1。

- **D1：新一轮机会的正式触发日。** 记录本轮当日真实客观异动`d123_trigger_evidence`及日期、来源。若首次发现仅凭单日爆发（`initial_discovery_basis=ONE_DAY_SURGE`），D1最多观察，禁止仅凭当天放量、上涨家数直接确认；若首次发现时已有可追溯且当时已可得的核心多日结构、真实驱动及独立参与证据，充分满足市场确认和新方向Gate，则**D1可直接确认**，并冻结`D1/CONFIRMED`，不必人为等到D2。
- **D2：本轮第二个有效收盘复核。** D1尚未确认则核实多日结构、产业持续性、广度、相对强弱、分歧承接与最强反证；证据充分当天直接`D2/CONFIRMED`并结束期限验证，不再推进D3。证据不足保持真实观察/候选、写出具体缺项，到下个有效收盘必须D3；不得把D2机械绑定候选。
- **D3：本轮第三个有效收盘，最后决定期限。** D1/D2未确认则必须选择`CONFIRMED`或`NOT_CONFIRMED`，不得PENDING、D4或继续观察。证据充分，冻结`D3/CONFIRMED`并每日复核；未确认，**本轮立即以`exit_reason_code=D3_NOT_CONFIRMED`移出正式有效池**，冻结最终八维审计、实际缺证与结论。研究到期未确认可属于整理/过渡期，不得伪称已发生价格破位或产业逻辑失效。缺少真实最终审计则BLOCKED，禁止伪造结果。
- **确认后**：D1/D2/D3任一阶段确认即冻结历史阶段、结论与日期；之后按真实市场状态每天检查持续性、回调承接、强反证和退出。冻结标签不是后续继续留榜的担保，已确认方向仍可有证据降级或结构性失效，但不重新进入D阶段。
- **退出后重启D1**：旧episode已经结束并有真实新异动时，新周期可在当轮独立全市场扫描中直接D1；如果此前D3未确认的冻结日早于本轮，即使本轮才完成旧记录清理，也允许同轮先退出旧episode再建新D1，不强制等下一交易日。必须先冻结新发现，再核对旧D3结论、旧退出、新触发日及客观结构变化；新D1不得沿用旧周期的确认和证据结论。若本轮才首次到D3而未确认，不可仅凭同一轮涨幅将其立刻重启D1规避终局；普通反弹、旧故事或换名称亦不可重启。不设固定冷却天数，核心是可溯源的新触发与旧周期已经终结。

**八维复核要求**：①外围市场与风险偏好；②主催化事实与可得时点；③真实产业链/供需订单利润传导；④资金参与的客观成交与换手口径（不伪称净流入）；⑤带样本分母的成分股广度；⑥相对全市场与同风格强弱；⑦核心申万三级行业的多日结构与承接；⑧最强反证、事件透支和资料缺口。不得用固定涨幅、量比、连续上涨天数代替证据。独立商品第一锚以其自身价格结构及供需佐证判断，A股反应滞后不能一票否决。

**时间及遗漏约束**：D1起算于本轮首次正式有效收盘，接下来的两个真实A股交易日分别为D2、D3；休市、海外商品交易日和同日修订不计数。行情缺失/漏审须报告BLOCKED和真实缺口，不得伪造复核或通过重启D1规避截止；现有程序只能直接核验连续已发布有效收盘记录，声称全部实际交易日无遗漏需另核对权威A股交易日历。

**完成结论的数据去向**：确认方向在`trends[]`冻结原D阶段、结论与结论日期，另列当轮`market_state`，继续日常趋势复核。D3未确认方向当轮退出，其`surge_followup`（若首次为单日爆发）及`confirmation_audit`完整终结快照保存于`scan_audit.state_migration_gate.exits[].d123_final_audit`；不在活跃榜继续展示“D3例外保留”。D3未确认的必要证据缺口必须写入当轮退出报告。

**历史存量兼容（2026-10-27及以前）**：历史D阶段、episode、市场结论及提交记录不得追改。2026-10-28起，对历史上已D3/NOT_CONFIRMED却仍留榜的方向，在首次正式收盘时按同一专用Gate退出并保留历史冻结结论；不得把旧“例外保留”解释为可无限跟踪。旧D3补标仅可根据当时已发布的市场状态和原Git证据恢复，绝不伪称历史曾完成D3八维矩阵。

## 3. 数据契约与下游资格

### 3.1 数据质量、来源和模型职责

研究使用覆盖完整、日期可靠的客观行情与可追溯产业证据。模型负责发现、反证和结论；Python只负责行情计算和技术校验，不自动作趋势决策。所有关键数据均须核对交易日、时间可得性、来源及覆盖范围；不足时披露缺口，禁止推测填补。

### 3.2 确认与爆发复核的审计字段

**历史数据兼容边界**：以下审计及handoff资格约束仅适用于`trade_date >= 2026-10-27`的新发布Registry/Handoff；此前已经冻结的正式结果、episode和状态不得回写。缺乏真实证据或要求的审计结构时，必须保持上一版正式文件不变并报告BLOCKED，禁止编造字段通过校验。

**字段层级**：`trends[]`顶层的`initial_discovery_basis`、`d123_trigger_evidence`、`d123_stage`及`d123_*decision*`属于episode及阶段审计；其中首次发现依据和触发证据一旦建立不得随日后行情改写。逐日可更新的`discovery_basis`、产业催化和状态证据则存入`confirmation_audit`。D3退出当天的完整终结审计保存在`scan_audit.state_migration_gate.exits[].d123_final_audit`，不得只写在已删除的`trends[]`条目中。

**每条有效趋势（观察/候选/确认）在`research/trend_registry.json#trends[]`必须包含`confirmation_audit`对象**，按北京时间18:30前已经可得的实际资料填写：

- `asof_trade_date`＝当轮收盘日；
- `market_environment`＝`NORMAL` / `EVENT_LIQUIDITY_SHOCK` / `RISK_OFF` / `MIXED` / `UNCERTAIN`，必须同时记录 `market_environment_reason`（可复核的市场环境归因）与 `market_environment_source`（实际核实的来源URL或仓库证据路径）；市场级集中资金流入不能作为产业确认的独立正证据；
- `driver_type`＝`INDUSTRIAL_GROWTH` / `CONTENT_COMMERCIALIZATION` / `COMMODITY` / `DEFENSIVE` / `OTHER`，仅用于同一榜内的驱动区别，不是新市场状态；`COMMODITY`必须与`trend_basis=COMMODITY`一致；
- `initial_discovery_basis`＝2026-10-28及之后新episode建立时冻结的首次发现依据（`ONE_DAY_SURGE`/`CONTINUING_STRUCTURE`/`SUSTAINED_FUNDAMENTAL`/`COMMODITY_STRUCTURE`），旧episode可保持历史缺省；`discovery_basis`＝本轮实际用于趋势判断的**当前证据基础**，允许新增持续结构后从`ONE_DAY_SURGE`升级为`CONTINUING_STRUCTURE`等，但不改写初始发现事实；仅凭单日爆发不允许提升到候选或确认；
- `catalyst_kind`＝`EVENT` / `SUSTAINED_DRIVER` / `COMMODITY_SUPPLY` / `UNVERIFIED`；`catalyst_fact`（经核对的事实、并指出尚属预期的部分）、`catalyst_source`（URL或有效research/data路径）、`catalyst_available_at`（包含真实时区偏移的ISO 8601时间，不得晚于当日北京时间18:30）；`UNVERIFIED`不能支撑候选或确认；
- **商品跨时区审计（2026-10-29起新增正式收盘）**：`trend_basis=COMMODITY` 的 `confirmation_audit.commodity_price_review` 必须说明 `reference_status`（AVAILABLE/UNAVAILABLE）、`completed_reference`（已完成海外交易时段的`instrument/trade_date/price_basis/source/available_at`；不可得则为null并说明缺失）、`current_session_status`（OPEN/SETTLED/CLOSED/HOLIDAY/UNAVAILABLE）、`current_quote`（可得盘中报价时的`observed_at/price_basis/source/finding`，无则null）、`completed_price_structure`（`status/finding/source`及用于结构判定的`completed_sessions`，已确认至少两条不同完成交易日的可核验报价记录）和`independent_supply_driver`（`status/finding/source`）。商品市场确认要求已完成时段多日结构和独立供需证据都得到支持；下游订单利润待兑现的影响只写入`transmission_gap`，不作为确认硬门槛。D3判`NOT_CONFIRMED`还需`market_blockers`逐项注明**与当轮结构/供需状态一致**的真实市场缺证类别（如缺多日价格、报价不可核验、供应独立证据不足、价格结构已反向证伪）；不得以当日尚未结算或利润未兑现作为`market_blockers`。校验器检查来源、真实时点及审计结构，不代替研究模型对事实真伪的判断。2026-10-28已发布冻结结果不追写，纠错按独立审计另记。
- `core_industry_codes`为原行业代码集合里的核心真实受益三级行业；`strongest_counter`为最有力的不利证据和缺口，`decision_reason`必须明确为何维持/升级/降级当前状态；`decision_state`与实际`market_state`完全一致；
- 非确认方向`specific_blocker`写清楚**不足以确认的哪项具体事实/结构**，禁用空泛“继续等待”；确认方向`first_sufficient_evidence_trade_date`为根据当时资料逐日追溯的首次充分证据日期，不能使用未来公开信息、不得伪造较早确认。确认时过热但趋势仍成立，应在理由里记录过热/迟到与个股WAIT边界。

- **新D1触发审计**：2026-10-28及之后新增episode均需`d123_trigger_evidence`，按原市场证据契约记录当日`SUPPORT`方向、可核验`dimension`、`impact`、`trade_date`、`source`及具体`finding`，用于证明新异动（不能仅用旧产业故事）；若同名旧方向重现，先独立冻结发现再核验其此前退出与本轮新增事实。

- **阶段展示与已完成结果**：正式Registry记录`d123_stage`、`d123_trigger_trade_date`、`d123_decision`、作出结论后的`d123_decision_trade_date`，与当轮真实`market_state`并列展示；D1如已有当时可得的充分独立多日结构也可直接`CONFIRMED`（纯单日爆发的D1不允许），D2证据充分可直接`CONFIRMED`并结束本轮；仍未确认的方向到D3必须判`CONFIRMED`／`NOT_CONFIRMED`。确认后保留`D1｜确认通过`、`D2｜确认通过`或`D3｜确认通过`作为冻结的历史结果，后续按完全相同的规则每日复核实时状态；已结束结果不能作为长期确认或继续留榜的担保。D3不确认必须通过独立`D3_NOT_CONFIRMED`期限退出Gate后移出正式榜，最后一轮完整审计写入`exits[].d123_final_audit`，禁止例外保留；不能将到期未确认冒充价格趋势破位或产业失效。D2/D3后不再增加阶段，不允许`POST_D3`、`UNVERIFIED`或`PENDING`充当D3结论；不得事后改写已冻结结论。

- **正式账本中的验证结构**：新单日爆发方向在原`trends[]`内记录`surge_followup`：`trigger_trade_date`、依序且不可改写的`sessions[]`、`decision`（PENDING/CONFIRMED/NOT_CONFIRMED）、`decision_trade_date`。每个`sessions[]`包含真实`trade_date`及八维`dimensions`，每项给`status`、可检验的`finding`和`source`；`funding_strength`须另注明`measurement_basis`（`PRICE_VOLUME_PROXY`成交价量代理／`VERIFIED_NET_FLOW`已验证净流向／`UNVERIFIED`）及`observation_window`，**成交量代理绝不证明资金实际净流入或买方身份**；当`breadth.status=SUPPORTED`时须提供真实`sample_size`和`advancing_count`，不得用无分母百分比冒充行业广度；若`market_environment=EVENT_LIQUIDITY_SHOCK`仍在D2/D3确认，须有`event_independent_evidence`记录资金冲击之外的独立行业事实、来源与审查状态。未核实如实为UNVERIFIED/INSUFFICIENT，正常市场不应被虚报为明确净流入。**D3结束不得再PENDING**；D3当天退出时在`exits[].d123_final_audit.surge_followup`保留最终第三次八维会话及不可改写的先前会话；`d123_final_audit`还必须包含`d123_stage=D3`、`d123_decision=NOT_CONFIRMED`、原始触发日、冻结结论日、退出前观察/候选状态、当轮`confirmation_audit`和独立八维`dimensions`（每项`status`/`finding`/`source`）；“NOT_CONFIRMED”只冻结本次三日初判，不禁止未来有新增证据再确认。已经完成的初判不可事后改成当时已确认。

### 3.3 产业状态、三级行业身份与handoff资格

研究完成后方可赋值正式数据字段，禁止先填状态再倒推理由。

- `trend_state`仅记录产业景气证据成熟度；`lifecycle_status`记录产业逻辑有效性。两者均须依据产业自身可追溯事实判断，不能由股价涨跌直接替代。`trend_state`不得作为`market_state`、`in_new_position_priority`、handoff资格或趋势强度与排名的直接判定依据；真实产业证据必须独立审查，不得以T等级标签替代。
- `market_state`在同一个趋势榜记录观察、候选或确认；A股主导趋势由A股结构支持，独立价格锚主导趋势可由可核验的基础市场价格结构支持，但需明确`trend_basis`及商品证据。三类状态均可持续跟踪，观察和候选都不能进入正式买点榜或正式个股研究。
- `industry_codes`、`industry_names`记录已核验的申万三级行业身份及名称；必须验证主营业务和实际受益关系，不得以概念相关性冒充真实行业归属。

- `in_new_position_priority`仅按本节独立确认的主题和三级行业路由资格设置；handoff中的行业代码、名称保持原主题顺序。观察/候选不得生成任何下游个股READY/WAIT/UNCERTAIN/DROP研究工作集。

**`industry_assessments`是唯一行业级身份与受益门槛**：每条候选或确认主题必须覆盖本主题每个`industry_code/name`，包含`benefit_level`（`CORE`/`DIRECT`/`RELATED`/`UNVERIFIED`）、独立`market_state`、当轮`evidence_trade_date`、可追溯`benefit_reason`与`market_reason`；只有`CORE/DIRECT`能被评为已确认受益行业，`RELATED/UNVERIFIED`可保留观察或候选但不得混入股票handoff。第一次发现的观察可只保留未核实行业映射，不强行填直接受益。

**handoff与买点**：`in_new_position_priority=true`仅限`趋势确认`。在`research/trend_handoff.json#signals`中，`market_state`必须为`趋势确认`且`industry_codes/names`必须仅含该主题在`industry_assessments`中独立`趋势确认`且`CORE/DIRECT`的三级行业，不能把整个宽主题路由转交。可以只有一部分三级行业进入handoff，且须保留原主题的行业顺序；若一个都没有，优先级必须为false、不能发布该股票研究信号。即使商品自身已确认但A股未确认，仍只保留商品趋势研究，不生产股票READY。候选与观察在原正式榜内持续复核，不流入19:00个股行动研究。19:00个股研究继续独立执行买点、收益风险比及风控Gate；趋势确认不等于可以买入。

`research/trend_handoff.json`是独立的下游交接文件（`schema_version=1`），不是趋势条目字段。其名单只能来自正式账本中实际获得优先资格的方向；产业阶段、市场状态、行业映射必须与账本一致，不能在交接时重新判断或改写。

### 3.4 数据校验与事实判断的责任边界

**程序责任边界**：`scripts/trend_registry.py`和`scripts/validate_trend_publication_pair.py`只强制字段、时间、三级行业身份/状态、结构性反证与handoff一致性；它们无法自动证明公司供应链订单真实、产业将增长、主催化的事实正确或新方案盈利，必须由模型使用可靠可得来源审慎判断。证据不足就不确认，不许人为满足Gate而伪造。

**同一交易日允许正式修订覆盖**：当日18:30首次收盘发布成功后，只要实际执行时仍为**同一北京时间交易日**，允许以同一收盘数据和新增核验资料修订并覆盖正式`research/trend_registry.json`；必须同步重算及成对校验`research/trend_handoff.json`，不得另存影子文件冒充唯一正式源，也不强制等待第二天。此模式在发布Gate中使用`scan_audit.same_day_revisions[]`保留每次修订的源Registry blob SHA、原生成时刻、真实修订时刻、具体修订原因及有来源的当日证据；沿用当日首次发布的`state_migration_gate`、独立发现冻结时点、episode身份及此前state_history，不擦除或伪造18:30首次发布历史。当天纠正已有状态时增加同日修订事件，但**不把它冒称为另一个交易日的D2/D3复核**。跨到下一北京时间自然日，禁止再用同日模式追写旧日榜单，下一有效收盘仍按原full_close跨日迁移；如当天新增或删除正式episode，原则上必须另作完整独立发现与退出审计，不得利用简化同日纠正流程绕过Gate。唯一有限纠错例外：首次发布的独立完整扫描已在冻结后的`candidate_disposition_audit`中明确记载`origin=MODEL_INDEPENDENT`的新方向，却因旧D3历史清理被错误延期；旧episode的D3未确认日期早于本交易日且旧退出审计已通过时，允许不伪造二次扫描、在`same_day_revisions[].new_episodes`中以原独立冻结时间、候选原决定、旧退出ID、当日全市场客观新增证据和Git源SHA保留完整纠错链，补录该方向的D1观察。该例外必须有专门迁移Gate、当日八维审计和配对Gate校验；首次发布扫描与原候选去向、原迁移/退出及旧state_history必须保持只读，并以同日纠错附录解释首次错误。未被原始模型独立发现的全新方向仍须另作完整独立扫描。无充分证据、配对校验失败或GitHub回读失败不得声称修订成功。修订后的版本即当日最新正式榜；回测可从Git提交历史恢复当日各版本，须区分18:30首次发布与同日修订。

## 4. 正式发布、校验与报告

**历史输入只读校验（06:30及18:30旧基线读取）**：从GitHub读取上一有效收盘Registry/Handoff原始文件，对这对旧文件运行现行严格配对校验：

~~~bash
python scripts/validate_trend_publication_pair.py \
  --registry /tmp/previous_registry.json \
  --handoff /tmp/previous_handoff.json
~~~

此检查只确认旧文件满足现行完整收盘结构，**不代表本轮新研究已发布**。所有日期一律使用严格校验，不再存在初始化基线特殊放行。失败时报告REGISTRY_BASELINE_UNAVAILABLE，不得静默继承旧趋势。18:30必须先冻结独立全市场发现，再读取这对旧文件，不得让旧名单影响独立发现。

正式收盘时，先冻结独立首轮，再按上述严格只读校验读取上一轮有效趋势账本。所有旧方向在`reviews`继续复核或`exits`有证据退出两者中必须且只能出现一次；正式账本保存观察、候选、确认，并依照既定业务资格生成handoff。**以下两项校验只用于本轮拟正式发布的文件，必须全部PASS，不得以旧文件的只读校验结果替代。**使用真实临时文件执行：

~~~bash
python scripts/validate_trend_state_migrations.py \
  --previous /tmp/previous_registry.json \
  --proposed /tmp/proposed_registry.json \
  --previous-blob-sha <真实上一版blob SHA>

python scripts/validate_trend_publication_pair.py \
  --registry /tmp/proposed_registry.json \
  --handoff /tmp/proposed_handoff.json
~~~

仅在全市场扫描确实完整时填写`scan_audit.full_market_scan_completed=true`。市场结构性退出缺少反证、D3期限退出缺少终局审计、漏审、数据不足或任一Gate失败都禁止正式发布。两份正式文件必须交易日、资格、排名和映射一致，提交后READBACK；如实报告失败环节。

**空交接与下游零信号**：若本轮有效`trend_handoff.json#signals=[]`，按成功完成的“无合格确认行业”处理：当天**不启动正式个股Top5深度研究，不写新的`trend_buy_formal_result.json`或`trend_buy_handoff.json`，不以旧名单或观察/候选凑榜**；应直接报告“NO_ELIGIBLE_CONFIRMED_TREND”，说明趋势榜本身仍按正常流程完成。不要把这类正常空信号误报为市场数据损坏；有合格信号但公司数据质量失效则按真实数据错误阻断，不混为同一情况。

中文报告及前端均直接展示同一正式账本里的**趋势确认、候选趋势、观察**，并对有D1—D3记录的每个在榜方向并列展示**当前市场状态**与**验证阶段／已冻结结果**：D1/D2/D3确认均按统一的每日复核与退出规则管理；已确认的D阶段记录是历史结果，不代表当天仍在D2/D3；D3未通过方向只在当轮退出审计和中文报告中显示“D3期限未确认—本轮退出”、关键缺项与冻结结论，不再占据有效榜；当第一锚来自独立报价市场时，还须分别报告第一锚价格结构与A股行业、个股的实际反应。新异动可概述，高潮/衰退、失效不逐项展示。报告仍包含新发现、有效旧趋势变化、重大反证、产业与市场背离、数据缺口和真实校验/提交结果。除展示过滤外不得调整市场状态或推荐资格。

19:00趋势买点榜、行情生产任务、盘中监测、持仓和趋势验证保持各自独立业务流程。下游只消费**同日已通过迁移及配对Gate**的正式handoff：仅趋势确认且独立CORE/DIRECT确认三级行业可路由；`signals=[]`属于有效无买点研究情形，输出`NO_ELIGIBLE_CONFIRMED_TREND`，不生成当日新股票榜、不沿用旧榜。候选或观察方向不得进入下游个股工作集，交接时也不得重新判定资格。
