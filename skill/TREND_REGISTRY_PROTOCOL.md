## 0. 每次执行前必读｜通用产业与市场研究标准

**产业链、商品价格第一锚与A股个股买点分开判断，但商品领涨与股票趋势仍在同一趋势榜和同一状态流中推进，不另建独立商品榜。** 研究对象是未来可能持续的产业景气及其在A股的市场体现；发现候选不等于趋势已确认，确认产业趋势也不等于立即值得买入。

1. **产业链的领先变量与未来1–2季度驱动**：判断未来1–2个季度盈利改善是否存在可核验路径；分开核实政策落地、产品价格/价差、库存与供需、订单与交付、产能利用、成本/毛利传导和经营利润。区分已发生事实、前瞻条件、未证实假设。单一政策口号、热点新闻、市场涨幅不足以证明盈利已改善。
2. **产业T阶段（证据成熟度而非股价级别）**：T0拐点观察——产业领先变量发生有来源的变化，但需求/利润传导尚不完整；T1准景气确认——多类有效证据支持未来1–2季度产业或盈利改善的驱动，关键传导与潜在反证已审查，尚未充分兑现；T2正式景气——有真实订单、供需、价格/价差、盈利或利润率等互相支持的兑现证据，产业链条相对充分。资料不足则待核验，不强凑T1/T2；正式迁移仍服从现行程序Gate。
3. **趋势市场阶段**：A股直接形成的趋势按相对强度、上涨广度、成交、价格结构、龙头与中票扩散及分歧承接判断；**主要商品直接形成的可核验价格趋势，可用商品自身多日价格结构、报价、供需与独立佐证推进同样的观察→候选→确认市场状态**，不要求先等A股价格反应。新异动为早期异动；观察为有跟踪价值但尚未确认；候选趋势为量价与扩散出现初步共振但持续性待验；趋势确认为市场结构、广度、相对强度与分歧承接获得相互支持的可靠确认；根据截至本轮有效收盘已掌握的真实证据判断，不设固定上涨天数、累计窗口或单日广度比例作为确认硬门槛；高潮/衰退为过热或扩散明显衰减；失效为按真实结构反证确认市场趋势结束。**状态不是必须逐级经过的机械序列**，要依客观证据判断。
4. **正向证据、反向证据和失效条件**：每个进入正式有效趋势池的主题都要有具体正向证据，主动核查至少一项潜在推翻路径，写明指标、条件及原判断何时应被修正；对关键产业结论尽可能用不同原始来源和不同证据类型交叉验证。若当前未找到真实反证，应注明“尚无已核实反证”并明确可证伪条件，**不能编造负面事实凑数**。同源转载不等于多源交叉。
5. **产业的专属第一锚**：资源品先检验现货/期货报价口径、供需、库存、产品价差和利润传导，再独立检查A股结构；化工类注意产品上涨与原料成本后的实际价差不同；装备/制造业注意新增订单、交付、产能和利润实现。所有行业都要检查A股公司主营与利润受益，而不是只看股票同涨。
6. **宏观风险、ETF与交易资格分离**：在产业和市场分析之外，核实整体成交、流动性、市场风险偏好对A股扩散及新仓时机的影响；宏观弱势不能自动把产业T等级下调。ETF只能作为研究完成后的参与工具、流动性和时机选择，不能反向证明产业逻辑。

**产业×市场交叉使用方式**：有产业证据但市场未确认的T0/T1/T2方向保留产业机会和市场观察价值；T1＋候选趋势主要观察；T1＋趋势确认且不过热、风险边界可靠时可研究新仓；T2＋候选/趋势确认可以进一步研究ETF；高潮/衰退、市场失效方向不进入当期新仓优先。**这些是参考框架，不能取代现行资格、排序和风险门槛，也不自动生成交易信号**。本轮研究范围不以2–3条为上限（观察/候选/确认都写入正式账本）；从其中符合原资格的方向形成当期通常2–3条新仓优先榜，合格不足就少于此数或为空。观察直接作为正式榜的有效跟踪状态，但不产生买点研究优先资格或READY；商品趋势同样只在原正式榜中发布。

**统一状态判断与迁移原则**：**所有历史产业阶段和A股市场状态都只是上一轮结论，不构成本轮默认判断或额外迁移门槛**。每轮研究依据截至本轮有效收盘的产业、市场正反证据重新评估本轮独立发现方向及仍需连续复核的观察/候选/确认方向；证据充分时及时升级或降级，不要求逐级迁移、连续上涨固定天数。仅证据确认走向高潮/衰退、失效且实际退出的方向，下一周期才须重新独立发现；从候选降观察不是退出，保持原episode与研究证据。证据不足则HOLD并记录已有信号、尚缺条件及下轮核实重点，不能机械照搬旧结论，也不能将没有新事实误写成全部旧证据已于当天重验。产业预期依独立供需、订单、价格、盈利等有效来源判断；此前核实且未被证伪的事实可沿用，不要求当天重复出现。趋势状态变化须有本轮新增、可溯源的结构证据及独立市场佐证；商品主导趋势可由可核验商品价格/供需结构直接提供证据，不能以缺乏A股扩散作为商品本身趋势的否决条件，综合广度、相对强度、成交、核心股与中位股扩散、分歧承接和关键反证；产业利好不能替代市场趋势确认。3/5日行情、70%广度、1.15倍量能等可作为参考统计，**不得充当固定等待期或一票否决的确认硬门槛**。程序校验证据日期、来源、独立维度和历史连续性，不自动证明结论，也不自行生成状态变更；确认趋势不自动形成新仓资格或个股READY。

### 0.1 趋势确认时点与核心结构连续性（2026-10-27审计修订）

本节修正“候选过久、集体爆发后才确认、首次分化即降级”的判断偏差；不改变产业T等级、市场状态枚举、正式研究流程、registry/handoff字段及下游READY风控。研究依据见 `research/backtests/trend_confirmation_timing_shadow_20261027.md`。该审计表明简单放宽3/5日/广度阈值的翌日表现并不可靠，**本节禁止把任一固定条件改为自动确认/自动降级**。

1. **优先评估结构形成，不等待集体普涨。** 候选主题在每轮收盘复核时，按可用的3/5日价格结构、相对强度、核心与中位股分布、量价、关键支撑与分歧承接，以及互相独立的产业证据，判断“原有趋势是否已可确认”，而不把本轮涨幅排名、单日普涨广度、放量大阳当成确认必需条件。若在市场普跌时有核心群体持续强于市场且回调未破坏价格结构，应主动复核是否已经形成趋势，允许按足够证据在当天直接确认；**一两只领先股、一次抗跌或单个涨停不等于行业确认**，缺少群体和跨维证据则维持候选并写明真正的证据缺口。既不要求连续上涨固定天数，也不把连续回调固定天数设为禁令。
2. **记录确认的“首次足够证据日”。** 从当次允许读取的候选/确认历史记录及截至各日实际可得的客观快照，逐日核对是否有早于本日的可靠市场结构证据。若确认恰逢板块大涨或高潮，`change_reason`必须说明此前候选为何还不足、今天补充了什么独立关键证据，并评估过热与失效位距离；如果发现过去判断迟缓，明确记为“确认滞后审计”，不假装过往已正式确认，也不以未来涨幅倒推过去证据。
3. **真实核心链优先，外围扩散单独记账。** 复合主题先说明原确认的主要产业链及已核实真实主营的核心样本、跟随样本和仅外围关联样本，核验当前研究对象与此前的一致性。某个外围子行业或小样本（如激光设备2只）出现单日普跌，不能在真实核心产业链的3/5日结构、相对强度及关键承接仍健康时，**单凭“多细分同步扩散消失”**把整条主题从确认降回候选；必须指出哪一条原确认所依赖的核心证据确实损坏。核心链自身实质破位、跨独立维度同步恶化时，不得借“原来仍强”推迟当日降级。
4. **确认/降级迁移与交易参与分离。** 初次降级前比较新增结构反证与上一确认依据的强弱，明确是普通分歧、核心结构破坏还是整个市场趋势证伪；证据不够时应HOLD并注明分歧风险，不为了稳定榜单而僵化保持。确认日如已大幅拉升、远离可核验失效位或收益风险比不足，报告必须说明“趋势确认不代表适合买入”；候选仍不得产生个股READY，所有买点与仓位遵守原流程。禁止以“为了提前买入”为理由降低证据可靠性。
5. **审计与验收**：任何新确认/降级均应在原有`change_reason`、`state_history.reason`和迁移审计证据中留下上述结构时点、核心对象、分歧承接、最强反证的可追溯理由；只增加必要兼容证据字段、保留原有registry/handoff文件和状态枚举、不凭未来行情追改历史确认。后续按当日可得证据做冻结成员滚动回测，综合确认提前量、确认后持续性和收益、错误确认、下游可执行性判断效果，不能只以单例胜出决定全局阈值。


### 0.2 正式榜直接跟踪观察和商品领涨（2026-10-27修正）

1. **没有独立的商品榜或观察上下文**：`research/trend_registry.json#trends`就是唯一的完整趋势研究列表，包含`观察→候选趋势→趋势确认`三个可持续跟踪的有效阶段；并非每次必须逐级迁移。观察不产生`in_new_position_priority`或买点READY。原`research/trend_handoff.json`仍只交接有资格的候选/确认A股研究方向。
2. **商品领涨照常走原流程**：对于原油、黄金、铜等主要商品，先核实具体商品/合约/报价/日期与多日价格结构、供需和反证；已形成趋势的品种可以在本榜从观察、候选升级确认，`trend_basis=COMMODITY`，`commodity_anchor`记录`instrument`、`trade_date`、`price_basis`、`source`和`trend_reason`。不存在A股对应映射或A股走势滞后，不是拒绝商品趋势升级的理由。商品T阶段仍按供需与利润传导独立给出，商品价格的“趋势确认”不自动给产业T1/T2。
3. **现有申万三级行业独立受益校核**：沿用当期申万三级行业数据，不重新创建映射系统。直接核验每个三级行业的主营受益与市场表现，最受益的一组行业可先确认，不等待其余宽主题行业普涨。正常A股主导趋势仍须结构、广度、相对强度等证据。若商品是第一趋势锚，三级行业可以在其`industry_assessments`里如实标注观察/候选而商品趋势先确认。
4. **个股慢反应是个股的独立判断**：确认商品趋势后，A股相关股票是否READY仍由原买点榜检查价格结构、入场触发、风险边界；不因商品确认就自动派发READY。没有合格A股买点时`in_new_position_priority=false`，但商品仍在趋势榜。任何商品主导趋势要进入handoff，仍必须有独立可核验的A股研究路由和资格。严禁用商品涨价直接当作炼化利润增长。
5. **发布与校验**：不新增发布文件和状态枚举，原有`scripts/trend_registry.py`和`validate_trend_publication_pair.py`负责观察连续性、趋势迁移和handoff隔离。期货价格不允许用过期报价伪装当日收盘；证据不足HOLD并写明缺口。已发布历史结论不因本轮策略修改被倒推为更早确认。


### 0.3 单日爆发只能触发观察；催化、产业链与外围市场先于确认（2026-10-27）

**强制纠偏：单日爆发不是趋势确认方法，不是与“核心结构提前确认”并列的候选确认算法。** 若本轮是仅凭单日大涨、放量、涨停潮、ETF普涨而新发现的方向，最多以`market_state=观察`进入现有正式趋势榜并持续复核；不得因为涨幅/广度/量比非常突出就直接设为候选或确认。若无可核验的真实研究对象或基本来源，则按已有新异动/未核验审计解释，不编造成观察。**该规则针对“只有单日爆发证据的新方向”；并不因已经确认的旧趋势某日爆发，就把其机械降为观察。**

做状态判断的**必答证据顺序**（允许客观并行采集，但研究结论必须逐项解释）：

1. **市场外围环境与资金性质**：检验大盘、风险偏好、流动性、宽基ETF异常净流、政策性/事件性普涨及风格切换；市场层面资金冲击造成的同步上涨只作背景，不能冒充独立产业确认。异常交易日与常态日分层审计；有明确大额净申购时，不推定具体资金持有人或“国家队”身份。
2. **行情引爆点（主催化）**：指出最早可得的一手催化事实（公司正式披露、监管文件、订单/产量/交付、政策或商品报价）、事件发生/发布/研究可见时间，拆分**已证实事实、市场预期、尚待兑现假设**。事件的规模、持续窗口、可逆风险和是否早被计价必须分析。无可归因主催化，不得仅凭板块大涨包装为产业趋势；没有新闻并不自动否定已有供需/订单/价格等持续性基础驱动。
3. **真实产业链与受益传导**：沿用已有申万三级行业，区分核心实质供应/主营受益、次级跟随与题材蹭概念。核实丝杠、关节执行器、减速器、电机、传感器、控制器等具体环节的技术/订单/量产/售价利润传导，不得把主机厂“准备量产”直接当作所有A股零件企业已获订单。若仅为主题概念相关，须注明受益证据缺口。
4. **市场持续结构**：核心三级行业的真实多日走势、相对市场优势、成交、成分股广度、回撤承接和反证是否构成**此前已存在并在本轮仍成立的连续证据**。首次单日涨停/成交放大仍是观察；后续有真实持续证据时可升候选；多日结构、核心受益和独立市场/产业事实已足够时及时确认，**不机械设必须等待N日或外围全部普涨**。从已有观察或候选升级当天恰好大涨，必须证明并注明“确认所依赖的以前和当天的独立证据”，不能把当日大涨本身写成唯一确认理由。
5. **确认时点与买点独立**：记录本轮是否只有单日爆发、主催化的事实与兑现阶段、独立核心行业支持/反证、首次足够证据日及没有确认的具体缺证；若首次确认时已明显加速，记录迟到/过热风险。确认不自动READY。仅凭单日爆发的代理回测只能检验“异常线索发现能力”，**不得作为趋势确认A/B胜率方案**。

**2026年10月机器人示例，必须按当时可得信息重演**：特斯拉官方在美东10月19日的年度股东资料中称V3 Optimus已为量产做好准备；10月20日A股机器人异动是“量产预期＋国内政策/产业事实＋市场资金表现”的**研究触发**。10月21日美东财报进一步披露Optimus开始早期生产，对中国A股10月21日收盘18:30之后才可得，不能用于追认10月20/21的正式结论；在北京时间10月22日复核时方可使用。即使主催化可信，也要核查中国供应商/申万三级行业的真实受益、之前多日结构与后续承接，不能仅凭10月20日涨幅直接判定必须确认；也不能因外围低样本板块未普涨而推迟核心趋势的合理确认时点。来源：<https://www.nbd.com.cn/articles/2026-10-20/4609364.html>、<https://www.sec.gov/Archives/edgar/data/1318605/000162828026066775/tsla-20260930.htm>。

**先后关系**：爆发＝发现线索；主催化/产业链＝解释为何有望持续；多日真实市场结构与独立佐证＝判断候选/确认。三者缺一环就须在现有账本写明缺口，不额外创建新榜。商品价格主导趋势仍以可得的商品价格多日结构和供需为主催化，不强求存在单日爆发。


## 1. 执行模式与三步主流程

### 1.1 06:30｜上一有效收盘版增量复核

读取上一有效交易日正式趋势账本中处于观察、候选趋势或趋势确认，且产业生命周期未失效的方向，对真实隔夜增量证据进行复核；无新事实则保留原状态与证据日期，不在早间改写正式收盘registry/handoff。已确认真正退出的方向不再自动继承；正式榜内观察方向必须继续读取、复核，不得遗忘。**读取上一收盘Registry/Handoff时执行下述历史输入只读校验，通过后再复核。**校验失败时报告REGISTRY_BASELINE_UNAVAILABLE。

### 1.2 18:30｜正式收盘研究

确认交易日期、收盘行情完成度和行业覆盖；仅在全市场扫描确实完整时将`scan_audit.full_market_scan_completed`记录为true。质量不足时阻断且**不能把本轮未发现解释成旧趋势失效**。

1. **独立发现**：研究模型先覆盖全行业及主要概念板块客观数据，再结合当期量价、行业/产业证据独立发现；**不能因旧池或热门板块限制扫描范围**。在独立首轮冻结前只可阅读本协议及当期客观证据；在没有读取上一轮registry/handoff/历史名单或旧候选转述前，冻结当日独立发现的方向、当前证据和反证。未知事实不得编造。独立发现可以为空，不能因为旧方向的名字而补齐。
2. **辅助交叉验证与连续复核**：独立发现冻结后，读取当日且时间口径有效的 `data/research/theme_evidence_snapshot.json#crosscheck_shortlist`（程序合并三级行业和已核验产业映射后排序，**0—3个方向**）。不排除模型已发现的方向，也不为补漏预留名额：重合则核对证据，未覆盖则补充研究，冲突则解释分歧；同源行情不能冒充独立证据。程序名单仅供复核，不能自动决定T阶段、市场状态、正式入榜或新仓资格。名单缺失/无效须标记辅助数据缺口，不得伪造复核结论，也不阻断模型独立研究。随后从GitHub读取上一轮Registry/Handoff，先运行下述「历史输入只读校验」，PASS后只复核其中处于**趋势确认/候选趋势/观察**且生命周期未失效的方向。对这三类方向保留历史证据和连续状态；真实证据不足时HOLD，充分时迁移。降至观察仍是下一轮必读对象。新异动、高潮/衰退、失效无需逐项复核；在新一轮独立发现中同名出现，必须建立本轮新episode_id及新first_seen_trade_date，不读取旧历史。
3. **合并、退出校验、发布**：将本轮观察、候选趋势、趋势确认写入**同一正式账本**；新异动、高潮/衰退、失效按真实证据退出；观察必须保留到下一交易日复核。旧有效趋势退出时，在`scan_audit.state_migration_gate.exits`记录真实原因和本轮独立市场结构反证；不生成额外历史文件。状态迁移Gate和registry/handoff成对Gate都通过后，才能安全提交两份正式文件并READBACK。

### 1.3 当期发现候选的落选审计（仅解释，不改变研究结论）

18:30独立发现冻结后、正式发布前，必须对**本轮模型已发现但未进入观察/候选/确认正式趋势池**的方向，以及**当日程序交叉复核名单 `crosscheck_shortlist` 中未进入正式趋势池**的方向，逐一解释去向。对程序名单同时记录是否已被模型独立覆盖，以及一致、补漏或冲突的复核结论；同源行情不得当作独立置信度加成。仅在已核实属于同一产业研究对象时合并审计，并列明对应原信号。程序完整计算快照中未进入最多3个复核名额的信号只保留排序/容量事实，不冒充已研究或否决。原模型独立发现冻结顺序不变；客观扫描分数只是复核线索，不能自动决定趋势资格或回填独立发现。

对每个落选方向至少说明：①当期可溯源的正向量价及产业证据；②市场结构（广度、相对强弱、3/5日等参考窗口、量能、核心与中票扩散）和产业盈利/供需/订单传导分别有哪些真实反证或未核实环节；③**没有进入正式池的决定性原因**，明确区分「当日反弹/新异动尚未确认」「产业证据不足」「市场结构未确认」「过热/衰退」「资料不足未完成复核」等，不能以“涨幅不够”“未入选”“排名靠后”代替分析，也不能编造反证；④哪项具体可验证的新增证据将触发下轮独立重新发现或重新评估。短期窗口为负、单日放量或固定上涨天数都不得成为机械一票否决项。

在正式Registry的`scan_audit.candidate_disposition_audit`中保存本轮**落选解释快照**（建议字段：`candidate_name`、`covered_industries`、`origin`、`decision`、`supporting_evidence`、`market_assessment`、`industry_assessment`、`decisive_reason`、`missing_evidence`、`recheck_trigger`），并在中文报告中按重要性摘要展示；来源或当日数据无法取得时明确标记`UNVERIFIED`，不得伪称已完成排除研究。最多3个复核名额之外的客观信号，保留在已有计算快照及其原始排序中，必要时汇总容量缺口；不得误写为模型已研究后否决。未形成有效信号的普通行业不需逐项列举。

这只是当轮决策可审计记录，不在正式`trends`之外新增观察池；已收录的观察方向与候选/确认一起进入下一轮连续研究，也不新增handoff字段、不改变T等级、市场状态、优先级、配对/迁移校验或发布硬Gate。新增审计字段为兼容性附加元数据，旧版Registry缺少该字段不构成历史基线错误。若本轮无法完整解释，应如实报告审计缺口，不能把缺失解释冒充为研究结论。

## 2. 必须保留的趋势研究纪律

**三种情况要分开处理：**

- **普通波动**：单日调整、局部分歧、某只龙头走弱或资金流出，不自动升降级；若核心证据仍成立，HOLD并记录风险。不能把“旧状态未被新事实推翻”冒充“今天已重新确认所有事实”。
- **A股真实退潮**：当日或已有行情显示市场结构发生实质恶化，且上涨广度、相对强弱或核心与中位股承接等独立反证提供支持时，按统一状态迁移规则及时下调market_state，**不要求固定天数，也不另走紧急通道**。若同日主要股票普跌、关键支撑真实破位，应及时审查而非机械等次日；即使相对抗跌也需独立核实自身结构。
- **产业关键驱动证伪与新证据**：产业T等级和lifecycle_status的下降，必须有商品/政策/订单/供需/盈利等**产业自身**新反证，不能只因A股板块下跌而标产业失效。当前跟踪周期的阶段提升不能只凭单日反弹；已退出方向重新被独立发现时，必须用本轮新证据独立认证，不能继承此前的失效或确认结论。

退出新仓榜不等于产业失效；A股market_state=失效不自动等于lifecycle_status=已失效；映射不足不等于产业不存在。原有历史状态必须忠实保存，实际新状态变化须写真实原因和日期。

**商品及跨市场**：资源品主题必须分别确认对应商品第一锚、产品价差、库存/供需、A股受益公司的真实利润传导和本地行情，不把同涨当成直接受益。化工等加工行业要区分产品售价、原料成本和真实产品价差。国际报价注明时区、现货/合约性质和是否最终收盘。数据及研究资源充足时，可附5/10个相关市场交易日的条件性情景、反证和到期回验；**前瞻/回验是辅助研究，不是当日正式发布的新增硬Gate**，也不能直接决定当日状态。资金流向同样仅可作注明窗口、口径及日期的辅助证据，不能单独改变状态或排名。

## 3. 数据使用原则

模型以真实、有效的A股行情及可核验的产业信息为依据，独立研究和发现趋势。

优先使用现有全市场客观量价统计，不要求模型逐只股票重复计算。Python仅负责数据计算和必要校验，不参与趋势推荐与判断。

所有关键数据必须核对交易日期、来源及覆盖范围。数据缺失或无法核实时应如实说明，不得推测或编造。

## 4. 趋势跟踪与退出机制

**正式趋势账本`research/trend_registry.json`保留市场状态为「趋势确认」「候选趋势」「观察」且产业生命周期未失效的方向；三个状态始终在同一榜单、同一状态迁移流程中。**

1. 本轮独立发现且具备观察/候选/确认真实证据的方向进入正式账本并承担下轮复核义务；新异动、高潮/衰退或失效按核实结论在报告中说明，不自动持久化。
2. 上轮仍有效的每个方向，本轮必须明确继续跟踪或有证据退出；独立扫描未命中，不等于该方向已经失效。
3. 继续跟踪时保持原`episode_id`、首次发现日期及`state_history`连续；观察↔候选↔确认等任意合法状态迁移均须本轮新增结构证据，不设机械等待天数。
4. 退出时直接从本轮`trends`移除，不保留非活跃条目；必须在本轮`scan_audit.state_migration_gate.exits`填写`episode_id`、`decision=EXIT`、前后市场状态、原产业阶段、具体退出理由、当轮真实市场结构反证及独立的广度或相对强弱佐证。校验器拒绝无依据退出或漏审删除。
5. 行情覆盖不足、交易日不一致、独立扫描失败时正式发布必须BLOCK；不得据此推断旧趋势失效。
6. 同名主题后来再被独立发现时，按本轮新证据建立新周期，不继承旧判断、首次发现日期或旧证据。

**退出不建立额外历史文件。** 既有Git提交记录足以支撑事后独立回测，日常模型不读取已退出记录。

## 5. 发布与报告

**研究结论与正式数据字段**

研究完成后再形成结构化结果，不得先选字段值、再倒推产业或市场证据。正式趋势账本中：

- `trend_state`记录产业景气证据阶段；`lifecycle_status`记录产业逻辑有效性。两者依据产业自身事实判断，不能由股价涨跌直接替代。
- `market_state`在同一个趋势榜记录观察、候选或确认；普通行业由A股结构支持，资源品可由独立商品价格结构支持，但需明确`trend_basis`及商品证据。三类状态均可持续跟踪，观察绝对不能直接进入买点榜。
- `industry_codes`、`industry_names`记录已核验的申万三级行业身份及名称；必须验证主营业务和实际受益关系，不得以概念相关性冒充真实行业归属。
- `in_new_position_priority`仅能由**候选/确认且有有效A股行业/个股研究路线**按现行资格和排序规则入选本轮下游买点研究优先范围，**不是买入信号，也不是个股READY结论**。候选趋势不允许在下游生成READY；个股READY须有趋势确认、独立买点结构及风险边界。WAIT、UNCERTAIN、DROP仍由下游按实际个股证据判断。

`research/trend_handoff.json`是独立的下游交接文件，不是趋势条目字段。其名单只能来自正式账本中实际获得优先资格的方向；产业阶段、市场状态、行业映射必须与账本一致，不能在交接时重新判断或改写。

**历史输入只读校验（06:30及18:30旧基线读取）**：从GitHub读取上一有效收盘Registry/Handoff原始文件，对这对旧文件运行现行严格配对校验：

~~~bash
python scripts/validate_trend_publication_pair.py \
  --registry /tmp/previous_registry.json \
  --handoff /tmp/previous_handoff.json
~~~

此检查只确认旧文件满足现行完整收盘结构，**不代表本轮新研究已发布**。所有日期一律使用严格校验，不再存在初始化基线特殊放行。失败时报告REGISTRY_BASELINE_UNAVAILABLE，不得静默继承旧趋势。18:30必须先冻结独立全市场发现，再读取这对旧文件，不得让旧名单影响独立发现。

正式收盘时，先冻结独立首轮，再按上述严格只读校验读取上一轮有效趋势账本。所有旧方向在`reviews`继续复核或`exits`有证据退出两者中必须且只能出现一次；正式账本保存观察、候选、确认，并依照既定业务资格生成handoff。**以下两项校验只用于本轮拟正式发布的文件，必须全部PASS，不得以旧文件的只读校验结果替代。**使用真实临时文件执行：

~~~bash
python scripts/validate_trend_state_migrations.py \
  --previous /tmp/previous_registry.json \
  --proposed /tmp/proposed_registry.json \
  --previous-blob-sha <真实上一版blob SHA>

python scripts/validate_trend_publication_pair.py \
  --registry /tmp/proposed_registry.json \
  --handoff /tmp/proposed_handoff.json
~~~

仅在全市场扫描确实完整时填写`scan_audit.full_market_scan_completed=true`。无市场结构反证退出、漏审、数据不足或任一Gate失败都禁止正式发布。两份正式文件必须交易日、资格、排名和映射一致，提交后READBACK；如实报告失败环节。

中文报告及前端均直接展示同一正式账本里的**趋势确认、候选趋势、观察**；资源品趋势须同时报告商品价势与对应已核实三级行业及个股反应差异，不能因此省略商品趋势。新异动可概述，高潮/衰退、失效不逐项展示。报告仍包含新发现、有效旧趋势变化、重大反证、产业与市场背离、数据缺口和真实校验/提交结果。除展示过滤外不得调整市场状态或推荐资格。

19:00趋势买点榜、行情生产任务、盘中监测、持仓和趋势验证保持其既定独立流程。下游只消费已成功正式发布的当期handoff；其接口字段、行业路由、排序与资格均保持不变。
