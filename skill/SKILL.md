# A股低风险买点榜｜V5 行业双确认 → 个股早启动

## 1. 唯一目标

寻找：

> **产业景气/行业盈利已经改善，市场资金开始关注并进入该行业，同时行业内部存在尚未充分上涨、正准备启动或刚启动的股票。**

V5 不从全市场个股 K 线开始选股。正式因果顺序必须是：

```text
行业景气与盈利改善
→ 市场开始交易这条基本面逻辑
→ 资金从行业向个股扩散
→ 在该行业内部寻找 PRE_BREAKOUT / FRESH_ACTIVATION / EARLY_EXPANSION
→ 公司基本面排雷
→ 最终少数公司深研
→ 给出价格阶梯与失效条件
```

任何跳过“行业景气 + 盈利 + 行业资金”而直接凭个股量价进入正式榜的做法都属于规则错误。

---

## 2. 第一门｜行业景气与盈利

行业必须先通过基本面门。正式可选行业只接受：

### `T1_PROSPERITY_CONFIRMED`
代表行业景气/盈利改善已经得到公司财务聚合数据支持。生成期硬条件等价于：

- `industry_trend == improving`；
- 行业收入同比中位数 >= 0%；
- 行业利润同比中位数 >= 10%；
- 核心盈利改善公司占比 >= 55%；
- 行业样本置信度至少 `medium`。

### `T2_PROFIT_TREND`
代表行业盈利趋势更强：

- 满足 T1；
- `industry_strength == strong`；
- 行业收入同比中位数 >= 5%；
- 行业利润同比中位数 >= 20%；
- 核心盈利改善公司占比 >= 60%。

不满足 T1/T2 的行业，即使当天涨得很强，也不得成为正式低风险选股行业。

行业估值不是第一门；行业是否真实改善才是第一门。

---

## 3. 第二门｜行业资金确认

行业基本面有效之后，再回答：

> **A 股现在是否已经开始交易这条基本面逻辑？**

正式市场阶段只接受：

### `FUNDS_TESTING`
资金刚开始试探：

- 行业市场 breadth 为 `broad`；
- activity 为 `normal/active`；
- 行业成交量中位数 / 20日均量 >= 1.05；
- 放量公司占比 >= 55%；
- breadth score >= 0.55。

### `TREND_FORMING`
资金趋势形成：

- `market_confirmation == strong`；
- breadth 为 `broad`；
- activity 为 `active`；
- 行业成交量中位数 / 20日均量 >= 1.05；
- 放量公司占比 >= 50%；
- breadth score >= 0.55。

只有：

```text
T1/T2
AND
FUNDS_TESTING/TREND_FORMING
```

的行业，才允许进入个股层。

“行业曾经很强”“行业今日单点暴涨”“只有龙头放量”“成交量接近常态但没有扩散”都不能替代这一门。

---

## 4. 第三门｜只在合格行业内部找早启动股票

正式股票池不是“技术形态好的所有股票”，而是**合格行业内部的早期扩散标的**。

允许的生命周期：

### `PRE_BREAKOUT`
准备突破：价格接近关键结构，量能已先行改善，但尚未完成大幅上涨。

### `ACCUMULATION_READY`
平台吸筹准备：仍处于低波动/平台区，1日和5日量能持续高于20日基准，20日涨幅仍低。

### `FRESH_ACTIVATION`
刚启动：突破得到价格 + 收盘 + 成交量确认，且距20日高点很近，说明是正在发生的新行情，而不是旧行情回落。

### `EARLY_EXPANSION`
早期扩散：趋势刚形成，20日涨幅仍受控、相对强度为正、5日方向为正、量能继续抬升。

### `REACCELERATION`
只允许非常早期的首次回踩后二次确认；必须重新放量上涨、重新站稳 MA20、20日累计涨幅仍不高。它是次级机会，不得优先于前四类。

---

## 5. 明确排除｜旧行情退潮不是低风险买点

以下股票不得进入正式深研池：

- 距20日高点回撤 >= 5%，且没有新的 re-acceleration；
- 距高点回撤 >= 3%，同时最近5日为负，且当天没有新的强放量上涨确认；
- 当日下跌 + 1日量比 >= 1.5 + 已从近期高点回撤 >= 3%，优先视为高位分歧/兑现，而不是“资金进入”；
- 高位区间中已经离开近期高点，且没有新的上涨量确认；
- 突破后跌回关键平台/MA20，同时5日方向继续转弱；
- `active_pullback` 但没有重新加速确认；
- 仅因为20日相对强度仍为正、历史曾经放量，就把退潮股重新选入。

原则：

> **成交量必须结合价格方向和行情生命周期解释。大成交量本身既可能是买入，也可能是兑现。**

---

## 6. 个股资金确认

最终进入公司研究池的股票必须显示“资金现在正在关注它”，而不是“过去关注过”。优先证据包括：

- `starting_breakout + breakout_confirmed + 1日量比 >= 1.3`；
- 上涨日 + 1日量比 >= 1.3 + RS20 > 0 + 距20日高点 <= 3%；
- 最近5日涨幅 >= 2% + 5日量比 >= 1.15 + RS20 > 0，且不是退潮；
- PRE_BREAKOUT / ACCUMULATION_READY 中量先于价持续抬升；
- 首次有序回踩后出现严格 REACCELERATION。

以下不算当前资金确认：

- 量比仅接近 1；
- 缩量反弹；
- 高位下跌放量；
- 从高点回撤后仅靠RS仍正；
- 过去一两周曾经放量，但当前量能已经消失。

---

## 7. 公司基本面排雷

行业已经通过景气/盈利门，不代表行业内每家公司都能受益。股票进入深研前仍需排除：

- 公司收入与核心利润明显恶化；
- 归母利润高增长但扣非明显弱或为负；
- 经营现金流与盈利长期明显冲突；
- 一次性收益、投资收益或联营收益主导利润；
- 行业盈利改善，但公司收入/核心利润没有得到传导；
- 重大减持、监管、诉讼、业绩预警或资本运作风险；
- 极端估值且核心增长不足。

PE/PB 仅做风险修正。禁止重新形成“低PE优先”。

---

## 8. Focused Deep Research｜最终 3–5 只

经过行业双确认、生命周期和公司排雷后，最终通常只研究 **3–5 只**；不足时按实际数量，不凑数。

每家公司原则上完成 2–4 次定向公开资料查询，至少回答：

1. 最新主营收入、归母和扣非盈利是否真实改善；
2. 利润改善来自主营还是一次性因素；
3. 行业景气为什么能传导到这家公司；
4. 是否存在近期重大减持/监管/诉讼/业绩预警/资本运作；
5. **为什么资金是现在开始选择它，而不是它过去已经涨过。**

优先公司公告、交易所、权威财经来源、行业一手数据。不得只读取 runtime 后就宣称“已深研”。

---

## 9. 最终状态

### `READY_TO_WATCH_ENTRY`
必须同时满足：

- 行业为 T1/T2；
- 行业资金为 FUNDS_TESTING/TREND_FORMING；
- 个股为早启动生命周期；
- 当前仍有方向性资金确认；
- 公司排雷与深研未发现破坏性风险；
- 当前价格没有明显追高。

### `WAIT_PULLBACK`
只允许用于**新启动但当前价格暂时偏离低风险区**的股票；不能用来收留 POST_PEAK_FADE。

### `OBSERVE`
主要用于行业逻辑有效但个股尚差最后启动确认的情况。不能无限期保留。

### `EXCLUDE_FADE`
上一轮行情已涨过，当前属于退潮/高位分歧/兑现风险。不给买入区间。

### `UNVERIFIED`
关键公司事实无法确认，不进入正式执行机会。

---

## 10. 正式榜价格阶梯

每只正式机会必须输出：

```text
股票｜行业｜行业景气｜行业盈利｜行业资金｜个股阶段｜状态｜当前价｜合理买入区间｜低风险买入区间｜失效价/条件｜第一阻力位｜深研结论｜核心风险
```

### 当前价
使用正式 runtime 对应 `trade_date` 的收盘价。

### 合理买入区间
在行业逻辑、资金趋势和个股启动结构仍有效时，可以参与且不属于明显追高的区间。依据：MA20/MA60、突破位、支撑、成交密集区、阻力、失效位。

### 低风险买入区间
比合理区间更保守，优先靠近已验证支撑、成交承接或突破回踩位。不存在可靠结构时写 `N/A`，禁止硬造价格。

### 失效价/条件
优先正式 runtime `invalidation_price`，或明确支撑破位条件。不得使用无依据的固定百分比止损。

### 第一阻力位
使用正式结构阻力；若真实处于价格发现阶段可写 `PRICE_DISCOVERY`，不得虚构目标价。

当前价已经高于合理买入上沿时不得标记 READY。

---

## 11. V5 的核心自检

每次正式发布前，对每只股票必须能顺序回答：

1. **这个行业为什么景气/盈利正在改善？**
2. **为什么市场资金现在开始进入这个行业？**
3. **为什么这只股票仍处于准备启动/刚启动，而不是涨过后的退潮？**
4. **为什么行业改善能传导到这家公司？**
5. **什么价格值得参与，什么条件说明判断错误？**

任一前置问题无法回答，不得因为后面的K线漂亮而进入正式榜。
