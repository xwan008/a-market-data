# A股趋势买点榜｜唯一正式业务规则

## 1. 目标
每日从已核验行业与合格公司中通过**唯一正式V4-B1流程**寻找下一交易日条件性趋势买点：Python全行业硬过滤与双通道Top5预筛 → 只对入选者做最新公告/扣非与预期深研并由模型排序 → 独立交易结构/失效/赔率Gate → 唯一正式Top5、READY/WAIT和handoff。**不存在原规则与V4两套并行正式发布**。模型名次是研究关注顺序，不等于交易许可；没有已验证买点时只能WAIT。

## 2. 唯一执行链
1. 读取同一完整交易日且通过正式配对Gate的 research/trend_handoff.json；按 TREND_HANDOFF_ROUTING_OVERRIDE.md 路由**仅已确认且直接受益**的申万三级行业。自2026-10-27起仅`market_state=趋势确认`允许正式个股行动研究：候选/观察继续在上游趋势榜跟踪，不进入当前个股工作集、Top5、WAIT或READY。下游不得自行升级行业；若同日handoff含候选或不合格三级行业，停止发布而不是降级后继续运行。
2. **零合格趋势可无新榜**：若本轮已完整发布且配对Gate通过的 `research/trend_handoff.json#signals=[]`，这是合法的 `NO_ELIGIBLE_CONFIRMED_TREND`，当天不启动Top5个股深研、不生成或覆盖新的 `research/trend_buy_formal_result.json` / `research/trend_buy_handoff.json`，并在19:00报告明确注明“无合格确认行业／未发布当日新买点榜”；不得重用前一日股票、伪造空公司工作集来凑READY/WAIT或把正常空信号当成失败。若存在合格信号但数据不齐或映射不合格，则仍BLOCK，不得以空榜掩盖数据质量错误。
3. 校验 data/low_risk/index.json、manifest和全部part，读取一次并Freeze公司working set；不得用旧行情、缺失部分或未来证据。
4. 只按 PRE_SCREEN_RESEARCH_SCOPE_OVERRIDE.md 的**V4-B1唯一本期预筛**执行：Python对已确认申万三级行业全部hard-eligible公司先计算同日10/20/60日相对强弱、近10日持续性、入场机会结构及已公告扣非财务；每个三级行业采用3席持续领涨+2席当前入场机会，严格最多5家公司，不再使用旧版70/30榜单或并列第6席。由`scripts/v4_prepare_research_candidates.py`产生`research/trend_buy_v4_candidates/latest.json`，按Git/财务来源哈希及交易日READBACK验证；模型无权替换候选范围。
5. 技术输入仍由行情数据分片和冻结历史工作集生成；V4程序对全行业执行有成本约束的Python指标和截至当日完整65根以上日K，同一价格口径差异>1.5%或未来K线一律拒绝；仅对被筛入的5家公司进一步构造完整近端结构与120～180日阻力，用于后续独立风险核验。拒绝读取未来价格或生成虚构预期，拒绝因涨得多机械排后、因价格低机械排前。
6. **先Python后模型**：只对V4当日程序入选的至多5只/申万三级行业进行公告、主营受益、扣非盈利、现金流、新产品订单、可追溯历史预期变化与重大反证深度研究；公司研究必须与程序入选代码集合严格一致。所有发布日、更新日及财务报告期<=本日且证据可追溯；无一致预期历史证据则标记UNKNOWN，不将同比增长伪称超预期。模型对有真实业务关联的公司提供本主题内唯一`v4_model_rank`和≥24字符`v4_model_reason`，未知/研究不完整阻断正式发布。已证伪公司DROP，不为补满5家提前扩大模型研究。
7. 按最新价量数据确定个股阶段：INITIATING（启动）、PULLBACK（分歧回踩）、REACCELERATING（承接后再加速）、REPAIRING（结构修复）、COOLING（新入场优势下降）、FAILED（确认结构失效）、TRANSITION（证据尚不足）。MA20/MA60是背景而非淘汰红线；单纯低于MA60不得直接DROP，单日放量也不得直接宣布有效趋势。
8. **先识别本次交易形态，再计算与其一一对应的失效位与赔率**。BREAKOUT必须有当日已确认的历史突破关口（已有价格/量能/收盘证据），以**本次突破关口被有效重新跌破**作为交易假设失效依据，不引用整段行情起涨低点；以关口下0.5%作为试运行风险缓冲参考。PULLBACK必须有当日真实回踩与反弹确认（MA20附近回踩低点在MA20下3%至上2%区间、当日收盘站回MA20、收盘强度≥55%、收盘高于前收且higher_low已核验），才使用**本次已确认的回踩日低点**下0.5%作为试运行失效参考。MA20、MA60、过去30日最低点、旧的通用support_invalidation和远期启动低点均不得单独代替本次买点失效位。0.5%缓冲和回踩距离均为待回测研究假设。止损失效价必须低于本次入场下沿，否则买点证据不足，保持WAIT，禁止伪造价位或将一笔新建仓风险延伸到趋势起点。只有来源于已独立确认三级行业的个股才有机会进入READY；候选/观察行业在上游研究，不通过正式handoff（旧版2026-10-26及更早仅作历史可读）；短线距离MA20超过8%、chase=high、正式风险大于6%或上方已知阻力不足1.5R均暂缓。READY需同时通过120～180日已确认历史阻力核验，上方有效阻力小于1.5R降为WAIT_RISK_REWARD。交易前需确定盘中与收盘触发方式，并考虑跳空/滑点，止损并非保证成交。
9. **唯一正式排序口径V4模型深研**：前置V4-B1程序候选不可被模型扩大；公司经同日模型公告/财务/预期反证审查后，READY/WAIT由`scripts/trend_buy_engine.py`独立风险准入决定，**READY先于WAIT，同状态内按同主题唯一`v4_model_rank`从小到大排序**；`attention_rank`逐项吻合。旧技术排序键可作风险说明和同等研究序位的技术核验，**不再替代V4模型顺序**。名次、技术强弱、基本面增速均不能授权买入。

   - **事实观察与假设边界：** 截至当日完成日K观察已入选股票；当日收盘站上此前5根日K最高价的1.002倍形成 `fresh_break`，还需当日量比≥1.3、收盘区间位置≥65%才记为排序里的“强5日突破观察”。收盘承接参考区只从此前1～3根完成日K选相邻两日收盘聚合（高/低收盘比差≤0.8%，中间不能已有后续收盘有效跌破），区分 `LOCAL_SUPPORT_HOLD`（盘中未有效刺破、收盘转强）和 `SAME_DAY_SWEEP_RECLAIM`（盘中刺破后收盘收复）。两种只是**当前规则下的价格观察标签**，不能证明首次承接、真正资金身份或以后有效；“未识别符合规则的收盘承接参考区”绝不等于市场不存在支撑。
   - **实际排序键（从左到右逐级比较）：** ①READY优先、WAIT随后（身份由原有准入Gate确定）；②是否过热（MA20上方偏离>8%或`chase_risk=high`先靠后）；③5日趋势层级（5日收益率为正且上涨日≥3、仅5日收益率为正、其他/数据不足）；④信号层级，依次为“强5日突破+参考区守住”“强5日突破+参考区刺破收复”“仅参考区守住”“仅参考区刺破收复”“仅强5日突破”“价格越过前5日高点但强度不足”“其他观察”；⑤相对强度与量价综合分（当日量比24%、5日量比16%、收盘位置20%、20日相对市场强度31%、5日上涨天数6%、MA60上方背景3%，每项使用代码内固定归一化）；⑥距MA20的**绝对**偏离；⑦仅参考区守住且有有效前期低点时的价格观察距离（未知不是零）；⑧股票代码作确定性平局处理。MA60上方仅作小幅背景加分，并不代表首次突破或形成买点。⑤是排序强弱代理，不是次日上涨概率；参数仍待跨日期回测，不能凭单次个股表现认定胜率提升。
   - **独立风控不可放松**：模型名次与结构状态绝对分离。READY/WAIT、6%风险上限、8%追高警戒、有效上方阻力≥1.5R、对应本次BREAKOUT/PULLBACK的失效位仍由交易引擎独立核验。参考区盘中刺破后收复不得用本日低点新造止损；没有成对买点和失效位仍保持WAIT。

   - **WAIT观察失效位不是未来推测价：** 对尚未确认的突破、回踩、MA20回升或MA60收复，仅显示同日结构支持的关注触发参考价，`reference_zone`、`invalidation_price`、理论风险与赔率留空；即使存在旧的起涨低点、历史枢轴或盘中一次触及均线，也不能包装成当前已成立的止损。如果个股BREAKOUT或PULLBACK已完成形态确认、但公司基本面/赔率等独立Gate仍阻止READY（此处的行业已由上游确认），则可在WAIT参考中展示**同一已确认形态**的买入与失效成对证据，仍不授权交易。未来回踩须等到新的完整K线实际承接，再根据那一日回踩低点重算，不得预先拿一轮上涨最低价压缩风险。明确区分“趋势已结束”和“本次建仓失败”，不使用涨幅回吐50%作为自动止损规则。
   - **结构与赔率证据：** 120～180日阻力使用截至信号日、左右各3根已确认的历史局部高点，选择高于同日收盘0.5%的最近有效枢轴；不足120根或没有可核实枢轴标记上方空间待核验。赔率按计划买入区最高价与对应结构失效价计算；若真实上方阻力低于计划上限，允许出现负赔率并禁止READY。历史阻力只是代理，不保证真实压制成交；有效突破后下一完整交易日重新计算。
   - **名单、模型研究次序和状态分离**：模型不修改V4程序入选集合，独立买点Gate计算READY/WAIT和DROP；READY优先展示，WAIT只观察。阻力与赔率检查仅可降级READY，不可凭研究名次提升状态；股票排名第一仍可能WAIT。
   - **正式输出解释**：`attention_rank`逐项跟随V4模型研究且READY先于WAIT；`attention_judgement`记录可追溯的`v4_model_reason`、本次价格形态和量价风险，不展示旧技术排序分数为唯一原因。`attention_resistance_check`保留结构阻力、风险赔率、追高警戒；`focus_watchlist`沿用最终主题Top5首位，WAIT不得发布为可执行买点。正式handoff保持原字段契约。
   - **数据与契约：** 赔率检查仅消耗本交易日冻结研究工作集和同日历史结构，不引入未来信息、不重复生成全市场结构、不修改交易交接字段契约、不自动下单。状态及排序参数属试运行研究代理，需要以历史可执行成交/止损的回测检验回撤、机会损失、胜率与交易次数。
10. 仅本次V4-B1程序入选并且**全部通过同日模型深研**的公司才可进入最终READY/WAIT/UNCERTAIN/DROP；程序名单、研究名单必须完全同一代码集合，每SW3最多5只，模型名次与解释需有真实证据。所有`fresh_company_research`、`working_set_frozen`、`pre_screen_coverage`、`company_research_coverage`、`structure_same_day`、`no_future_evidence`和`json_schema_valid`正式Gate必须通过。唯一正式结果`research/trend_buy_formal_result.json`及handoff需Git SHA/READBACK，任一关键环节失败阻断，不以旧规则或旧榜替代。
11. 仅完整19:00研究通过且正式结果READBACK后，scripts/trend_buy_handoff.py从动态主题Top5中提取READY/WAIT形成 research/trend_buy_handoff.json，仍遵守trend_buy_handoff_v2交易字段契约。盘中只按INTRADAY_MONITOR_CANONICAL.md监测交接名单，不重新选股或自动下单。

## 3. 状态含义
- READY：经证据核实，行业趋势确认且价格形态、合理区间、结构失效及风险全部就绪；仅下一交易日条件性入场，非无条件买单。
- WAIT：来自**已确认三级行业**、但个股本次未满足买点的研究结果；包括MA60下方的修复、启动未确认、分歧后的等待承接。正式handoff中WAIT必须清空可执行交易计划字段，改用独立watch_reference传递由正式研究动态Top5计算的近端观察触发价/参考区间（可以为空）；远期突破高点不得冒充当前买点，观察参考位也不得冒充持仓止损。WAIT触及观察区不自动升级READY，不改变板块确认Gate，也不凭任何单一外部价格上涨信号执行买入；下一完整交易日重新计算和确认。
- UNCERTAIN：业务或关键结构缺失，不得补造数据。
- DROP：业务关联被证伪、重大硬风险或已验证结构失效；MA60和单日回落均不是充分淘汰理由。
- COOLING与正式WAIT是不同维度；暂停新建仓优先排名不直接命令已持有的用户止盈止损。持仓退出根据独立结构保护、业务逻辑证伪与风险预算执行。

## 4. 交易时间与异常
北京时间工作日19:00执行完整研究，使用当天已完成行情发布；非正式交易日不把旧数值当新信号。研究证据、市场数据、代码审计、GitHub提交或READBACK任何一项关键失败，不写新正式结果或handoff。连续多日行情指标只是形态代理，不证明实际资金身份，也尚未证明超额收益；生产参数须通过严格截至当日日K的历史回放验证。
