# A股趋势买点榜｜唯一正式业务规则

## 1. 目标
每日从已核验行业与合格公司中通过**唯一正式流程**寻找下一交易日条件性趋势买点：Python全行业硬过滤与双通道Top5预筛 → 只对入选者做最新公告/扣非与预期深研并由模型排序 → 独立交易结构/失效/赔率Gate → 唯一正式Top5、READY/WAIT和handoff。**只有一套可发布的研究和交易准入规则**。模型名次是研究关注顺序，不等于交易许可；没有已验证买点时只能WAIT。

## 2. 唯一执行链
1. 读取同一完整交易日且通过正式配对Gate的 research/trend_handoff.json；按 TREND_HANDOFF_ROUTING_OVERRIDE.md 路由**仅已确认且直接受益**的申万三级行业。自2026-10-27起仅`market_state=趋势确认`允许正式个股行动研究：候选/观察继续在上游趋势榜跟踪，不进入当前个股工作集、Top5、WAIT或READY。下游不得自行升级行业；若同日handoff含候选或不合格三级行业，停止发布而不是降级后继续运行。
2. **零合格趋势可无新榜**：若本轮已完整发布且配对Gate通过的 `research/trend_handoff.json#signals=[]`，这是合法的 `NO_ELIGIBLE_CONFIRMED_TREND`，当天不启动Top5个股深研、不生成或覆盖新的 `research/trend_buy_formal_result.json` / `research/trend_buy_handoff.json`，并在19:00报告明确注明“无合格确认行业／未发布当日新买点榜”；不得重用前一日股票、伪造空公司工作集来凑READY/WAIT或把正常空信号当成失败。若存在合格信号但数据不齐或映射不合格，则仍BLOCK，不得以空榜掩盖数据质量错误。
3. 校验 data/low_risk/index.json、manifest和全部part，读取一次并Freeze公司working set；不得用旧行情、缺失部分或未来证据。
4. 只按本协议第5节的**唯一程序预筛**执行：Python对已确认申万三级行业全部hard-eligible公司先计算同日10/20/60日相对强弱、近10日持续性、入场机会结构及已公告扣非财务；每个三级行业先按持续领涨取3席、再从具备**可验证当前入场结构**的未入选股票取2席；不足2个入场资格时可用已验证历史与财务的持续领涨候选补足，标记`BACKFILL`，不冒充入场机会，严格最多5家公司。**当前无法入场、COOLING或`low_risk_eligible=false`不能单独取消领涨通道参评资格**，但不赋予READY；历史或关键财务数据不可信仍不得参评。由`scripts/prepare_trend_buy_candidates.py`产生`research/trend_buy_candidates/latest.json`，按Git/财务来源哈希及交易日READBACK验证；模型无权替换候选范围。
5. 技术输入仍由行情数据分片和冻结历史工作集生成；正式程序对全行业执行有成本约束的Python指标和截至当日完整65根以上日K，同一价格口径差异>1.5%或未来K线一律拒绝；仅对被筛入的5家公司进一步构造完整近端结构与120～180日阻力，用于后续独立风险核验。拒绝读取未来价格或生成虚构预期，拒绝因涨得多机械排后、因价格低机械排前。
6. **先Python后模型**：只对正式当日程序入选的至多5只/申万三级行业进行公告、主营受益、扣非盈利、现金流、新产品订单、可追溯历史预期变化与重大反证深度研究；公司研究必须与程序入选代码集合严格一致。所有发布日、更新日及财务报告期<=本日且证据可追溯；无一致预期历史证据则标记UNKNOWN，不将同比增长伪称超预期。模型对有真实业务关联的公司提供本主题内唯一`model_rank`和≥24字符`model_reason`，未知/研究不完整阻断正式发布。程序入选后，即使同日公司业务关联被证伪（`NOT_SUPPORTED`），也保留在这一轮冻结审查集合并由引擎记为DROP，不能释放研究席位或以其他股票递补。
7. 按最新价量数据确定个股阶段：INITIATING（启动）、PULLBACK（分歧回踩）、REACCELERATING（承接后再加速）、REPAIRING（结构修复）、COOLING（新入场优势下降）、FAILED（确认结构失效）、TRANSITION（证据尚不足）。MA20/MA60是背景而非淘汰红线；单纯低于MA60不得直接DROP，单日放量也不得直接宣布有效趋势。
8. **先识别本次交易形态，再计算与其一一对应的失效位与赔率**。BREAKOUT必须有当日已确认的历史突破关口（已有价格/量能/收盘证据），以**本次突破关口被有效重新跌破**作为交易假设失效依据，不引用整段行情起涨低点；以关口下0.5%作为试运行风险缓冲参考。PULLBACK必须有当日真实回踩与反弹确认（MA20附近回踩低点在MA20下3%至上2%区间、当日收盘站回MA20、收盘强度≥55%、收盘高于前收且higher_low已核验），才使用**本次已确认的回踩日低点**下0.5%作为试运行失效参考。MA20、MA60、过去30日最低点、通用support_invalidation和远期启动低点均不得单独代替本次买点失效位。0.5%缓冲和回踩距离均为待回测研究假设。止损失效价必须低于本次入场下沿，否则买点证据不足，保持WAIT，禁止伪造价位或将一笔新建仓风险延伸到趋势起点。只有来源于已独立确认三级行业的个股才有机会进入READY；候选/观察行业在上游研究，不通过正式handoff；短线距离MA20超过8%、chase=high、正式风险大于6%或上方已知阻力不足1.5R均暂缓。READY需同时通过120～180日已确认历史阻力核验，上方有效阻力小于1.5R降为WAIT_RISK_REWARD。交易前需确定盘中与收盘触发方式，并考虑跳空/滑点，止损并非保证成交。
9. **唯一正式Top5关注排序**：前置唯一正式程序候选不可被模型扩大；公司经同日模型公告/财务/预期反证审查后，READY/WAIT由`scripts/trend_buy_engine.py`独立风险准入决定，**READY先于WAIT，同状态内按同主题唯一`model_rank`从小到大排序**；`attention_rank`逐项吻合。技术风险信号仅作事实说明及独立风控，**不得替代模型研究顺序**。每个主题的模型名次不允许重复，因此不存在技术分数打破研究名次平局。名次、技术强弱、基本面增速均不能授权买入。

   - **事实观察与假设边界：** 截至当日完成日K观察已入选股票；当日收盘站上此前5根日K最高价的1.002倍形成 `fresh_break`，还需当日量比≥1.3、收盘区间位置≥65%才记为“强5日突破观察”。收盘承接参考区只从此前1～3根完成日K选相邻两日收盘聚合（高/低收盘比差≤0.8%，中间不能已有后续收盘有效跌破），区分 `LOCAL_SUPPORT_HOLD`（盘中未有效刺破、收盘转强）和 `SAME_DAY_SWEEP_RECLAIM`（盘中刺破后收盘收复）。两种只是**当前规则下的价格观察标签**，不能证明首次承接、真正资金身份或以后有效；“未识别符合规则的收盘承接参考区”绝不等于市场不存在支撑。
   - **正式排序唯一依据：** 对所有符合最终展示资格的READY/WAIT先整体排序（READY优先、同状态按主题内唯一模型名次升序），再截取主题Top5；不得先按近端触发、参考区、`primary/watches`等分类截满五席。`entry_opportunity`仅是展示标签，不能成为排序或隐式过滤条件。COOLING/FAILED结构不进入最终展示Top5，但仍须保留研究审计和独立风险判定。量价、均线、历史承接与局部突破仅作事实说明及独立风控。
   - **独立风控不可放松**：模型名次与结构状态绝对分离。READY/WAIT、6%风险上限、8%追高警戒、有效上方阻力≥1.5R、对应本次BREAKOUT/PULLBACK的失效位仍由交易引擎独立核验。参考区盘中刺破后收复不得用本日低点新造止损；没有成对买点和失效位仍保持WAIT。

   - **WAIT观察失效位不是未来推测价：** 对尚未确认的突破、回踩、MA20回升或MA60收复，仅显示同日结构支持的关注触发参考价，`reference_zone`、`invalidation_price`、理论风险与赔率留空；即使存在远期起涨低点、历史枢轴或盘中一次触及均线，也不能包装成当前已成立的止损。如果个股BREAKOUT或PULLBACK已完成形态确认、但公司基本面/赔率等独立Gate仍阻止READY（此处的行业已由上游确认），则可在WAIT参考中展示**同一已确认形态**的买入与失效成对证据，仍不授权交易。未来回踩须等到新的完整K线实际承接，再根据那一日回踩低点重算，不得预先拿一轮上涨最低价压缩风险。明确区分“趋势已结束”和“本次建仓失败”，不使用涨幅回吐50%作为自动止损规则。
   - **结构与赔率证据：** 120～180日阻力使用截至信号日、左右各3根已确认的历史局部高点，选择高于同日收盘0.5%的最近有效枢轴；不足120根或没有可核实枢轴标记上方空间待核验。赔率按计划买入区最高价与对应结构失效价计算；若真实上方阻力低于计划上限，允许出现负赔率并禁止READY。历史阻力只是代理，不保证真实压制成交；有效突破后下一完整交易日重新计算。
   - **名单、模型研究次序和状态分离**：模型不修改程序入选集合，独立买点Gate计算READY/WAIT和DROP；READY优先展示，WAIT只观察。阻力与赔率检查仅可降级READY，不可凭研究名次提升状态；股票排名第一仍可能WAIT。
   - **正式输出解释**：`attention_rank`逐项跟随正式模型研究且READY先于WAIT；`attention_judgement`记录可追溯的`model_reason`、本次价格形态和量价风险，不再以历史技术排序分数解释正式排名。`attention_resistance_check`保留结构阻力、风险赔率、追高警戒；`focus_watchlist`沿用最终主题Top5首位，WAIT不得发布为可执行买点。正式handoff保持原字段契约。
   - **数据与契约：** 赔率检查仅消耗本交易日冻结研究工作集和同日历史结构，不引入未来信息、不重复生成全市场结构、不修改交易交接字段契约、不自动下单。状态及排序参数属试运行研究代理，需要以历史可执行成交/止损的回测检验回撤、机会损失、胜率与交易次数。
10. 仅本次唯一正式程序入选并且**全部通过同日模型深研**的公司才可进入最终READY/WAIT/UNCERTAIN/DROP；程序名单、研究名单必须完全同一代码集合，每SW3最多5只，模型名次与解释需有真实证据。所有`fresh_company_research`、`working_set_frozen`、`pre_screen_coverage`、`company_research_coverage`、`structure_same_day`、`no_future_evidence`和`json_schema_valid`正式Gate必须通过。唯一正式结果`research/trend_buy_formal_result.json`及handoff需Git SHA/READBACK，任一关键环节失败阻断，不以替代规则或历史榜替代。
11. 仅完整19:00研究通过且正式结果READBACK后，scripts/trend_buy_handoff.py从动态主题Top5中提取READY/WAIT形成 research/trend_buy_handoff.json，仍遵守trend_buy_handoff_v2交易字段契约。盘中只按INTRADAY_MONITOR_CANONICAL.md监测交接名单，不重新选股或自动下单。

## 3. 状态含义
- READY：经证据核实，行业趋势确认且价格形态、合理区间、结构失效及风险全部就绪；仅下一交易日条件性入场，非无条件买单。
- WAIT：来自**已确认三级行业**、但个股本次未满足买点的研究结果；包括MA60下方的修复、启动未确认、分歧后的等待承接。正式handoff中WAIT必须清空可执行交易计划字段，改用独立watch_reference传递由正式研究动态Top5计算的近端观察触发价/参考区间（可以为空）；远期突破高点不得冒充当前买点，观察参考位也不得冒充持仓止损。WAIT触及观察区不自动升级READY，不改变板块确认Gate，也不凭任何单一外部价格上涨信号执行买入；下一完整交易日重新计算和确认。
- UNCERTAIN：业务或关键结构缺失，不得补造数据。
- DROP：业务关联被证伪、重大硬风险或已验证结构失效；MA60和单日回落均不是充分淘汰理由。
- COOLING与正式WAIT是不同维度；暂停新建仓优先排名不直接命令已持有的用户止盈止损。持仓退出根据独立结构保护、业务逻辑证伪与风险预算执行。

## 4. 交易时间与异常
北京时间工作日19:00执行完整研究，使用当天已完成行情发布；非正式交易日不把过期数值当新信号。研究证据、市场数据、代码审计、GitHub提交或READBACK任何一项关键失败，不写新正式结果或handoff。连续多日行情指标只是形态代理，不证明实际资金身份，也尚未证明超额收益；生产参数须通过严格截至当日日K的历史回放验证。

## 5. 程序预筛与深研边界（唯一生效）

1. **输入**：只接收同日期已确认且直接受益的申万三级行业，验证冻结行业公司表、全部manifest和part、公司指数、财务来源哈希及已完成日K。硬过滤ST/退市、非正价格或MA20/MA60、缺少至少一项正值PE_TTM/动态PE/PB、缺少营收同比或归母净利润同比、以及营收同比<-20%且归母净利润同比<-50%的公司（两项恶化须同时成立）；单独低于MA60不是淘汰理由。有效K线不足65根、价格口径差异超过1.5%、未来数据，一律拒绝进入候选。
2. **两通道，最多五席**：所有硬合格且具备有效65根以上同日历史K线的同业先计算10/20/60日相对行业中位数收益分位和近10日上涨持续性；持续领涨通道不受当日入场机会标签限制，取3家。入场位置通道只从有同日核验机会结构的未入选公司取2家；不足2席时允许用已核验领涨同业补足，明确标记`BACKFILL`，不捏造交易条件。跨通道去重，最多5家。可比样本不足3家时阻断本行业分位推断，当前工作流因此停止正式发布，不擅自放宽资格。
3. **持续领涨分**：`continuity=0.40×20日分位+0.30×60日分位+0.20×10日分位+0.10×近10日上涨次数分位`；`leadership=0.80×continuity+0.20×fundamental`。
4. **入场位置分**：`entry=0.65×entry_reference+0.20×price_structure+0.15×fundamental`。财务基础分优先采用审计时点可验证的扣非净利润同比，缺失时按扣非EPS或归母同比回退；同时核对经营现金流、非经常性收益与估值。高同比不等同超市场预期。
5. **财务证据语义**：`financial_publication_date_verified=true`仅表明同一家公司的F10来源标识、财报期、公告日期、更新日期均经截至交易日校验；不代表所有财务值可靠或具有超预期表现。`source_financial_provenance_verified_count`是当日已完成该来源日期核验的公司数，财报核心指标是否可用另行标记。模型必须核实并区分证据缺口。
6. **模型深研**：严格仅研究 `research/trend_buy_candidates/latest.json` 中已经冻结的公司，`reviews`代码集合必须与程序候选一致；每个主题内核验唯一整数 `model_rank` 和不少于24字 `model_reason`，标注来源时间、财报报告期、商业传导和反证。不知道的一致预期标记UNKNOWN，不得捏造。
7. **发布**：研究文件须经代码集合、数据日、财务SHA、来源时效和READBACK校验。模型只决定同READY/WAIT层内的研究关注顺序，交易形态、失效位、风险上限和赔率仍由引擎独立判定。失败仅BLOCK，不重新启用替代选股。
